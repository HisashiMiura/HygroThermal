## 評価方法の節とコードの対応

評価方法の各節が、プログラムのどこで計算されているかを示す。モジュールは `modules/` の下のファイルである。

| 評価方法の節 | モジュール |
|---|---|
| 湿り空気と水の性質 | `air_water_properties`、水蒸気圧は `state` |
| 材料の性質 | `materials`、式の形の部品は `material_props` |
| 壁の構成と質点 | `wall_geometry`、初期の状態は `wall_builder` |
| 熱・水分の流れ | 抵抗は `wall_geometry`、流れは `balance` |
| 太陽位置 | `solar_position` |
| 外気の条件 | `outdoor_climate` |
| 室内の条件 | `indoor_climate` |
| 外表面の日射・夜間放射 | `surface_radiation`、外表面の方位角は `direction` |
| 通気層の換気 | `wall_geometry`（`AirNode.ventilation_rate`）、質点ごとに並べるのは `balance` |
| 熱・水分の収支 | `balance`、質点の水分量と熱容量は `wall_geometry` |
| 1 ステップの解き方 | `solver`、ニュートン法は `newton` |
| 時間の進め方 | `simulation` |

入力から出力まで順に計算していく節は、1 つのモジュールに対応させている。質点やつながりなどの部品の性質を定める節は、部品のクラスのメソッドに分かれている。

式ごとの対応は、表にせず、コードに書いている。

- 関数・メソッドの説明（docstring）の Notes に、対応する節と式の番号を書いている（例：「計算方法の文書の『熱・水分の収支』の式 (9) に対応する」）。
- 計算する行のコメントに、「式 (k)」と書いている。節の名前のないものは、そのモジュールの説明（docstring）に書いた節の式である。

ある式を計算している所を探すときは、節の名前と「式 (k)」で、`modules/` の下を検索する。コードの「式 (k)」の番号がその節にある式の番号か、評価方法のすべての式がコードのどこかで参照されているかは、テスト（`test/test_doc_references.py`）で確かめている。
