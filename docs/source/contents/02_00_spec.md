## 評価方法の式とコードの対応

評価方法の各節の式が、プログラムのどこで計算されているかを示す。モジュールは `modules/` の下のファイルである。

評価方法の節のうち、入力から出力まで順に計算していく節は、1 つのモジュールに対応させている。質点やつながりなどの部品の性質を定める節は、部品のクラスのメソッドに分かれている。どちらの場合も、関数・メソッドの説明（docstring）に、対応する節と式の番号を書いている。

### 湿り空気と水の性質

| 式 | 内容 | コード |
|---|---|---|
| 3 節の表 | 空気と水の値 | `air_water_properties` の `R_V`・`L_V`・`C_W`・`RHO_W`・`C_A` |
| (1) | 飽和水蒸気圧 | `air_water_properties.get_p_vs` |
| (2) | 水分化学ポテンシャル | `air_water_properties.get_mu` |
| (3) | 相対湿度 | `air_water_properties.get_rh` |
| (4) | 水蒸気圧 | `state.State.p_v` |
| (5) | 水蒸気の密度 | 使うところで計算する（`wall_geometry.AirNode.water_amount`、`balance.moisture_residual_is`） |
| (6) | 空気の密度 | `air_water_properties.get_rho_a` |

### 材料の性質

| 式 | 内容 | コード |
|---|---|---|
| 3 節 | 熱伝導率・比熱・乾燥密度 | `materials.Material` の `lambda_h`・`c_s`・`rho_s`、容積比熱は `c_rho` |
| 4 節 | 平衡含水率（式で与える形） | `material_props.FormulaIsotherm.u` |
| (1)・(2) | 平衡含水率（係数で与える形） | `material_props.PowerExpIsotherm.u` |
| 5 節 | 湿気伝導率（一定の値） | `material_props.ConstantVaporConductivity.lambda_dsh_m` |
| (3) | 湿気伝導率 | `material_props.PowerExpVaporConductivity.lambda_dsh_m` |
| (4) | 液水拡散係数 | `material_props.PiecewiseExpPolyDiffusivity.d_w`（0 の材料は `NoLiquidDiffusivity`） |
| (5)・(6) | 液相水分伝導率 | `materials.Material.get_lambda_dsh_mu_l` |

### 壁の構成と質点

| 式 | 内容 | コード |
