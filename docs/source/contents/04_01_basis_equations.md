# 支配方程式と離散化

## 1 はじめに

本節では、このプログラムで解く熱・水分の式を、保存の式から導き、質点ごとの式（「{doc}`熱・水分の流れ <03_05_eval_flows>`」「{doc}`熱・水分の収支 <03_11_eval_balance>`」）にするまでの考え方と、選んだ理由を示す。

- 前提（2 節）
- 状態量（3 節）
- 流れの式（4 節）
- 収支の式の導き方と近似（5 節）
- 最終的に使う式（6 節）
- 水蒸気の流れを水蒸気圧の差のまま使う理由（7 節）
- 表面の境界（8 節）
- 通気層の空気の収支（9 節）
- 質点ごとの式への離散化（10 節）

## 2 前提

1. 壁の厚さ方向の 1 次元の問題とする。
2. 材料の中の水分は、液水と水蒸気の 2 つの相で保持される。氷は扱わない。
3. 材料の中の各点で、液水と水蒸気は常に平衡している（局所平衡）。そのため、水分の状態は 1 つの量（水分化学ポテンシャル）で表せる。
4. 材料は均質で、方向による違いがない。
5. 平衡含水率に吸放湿の履歴はない（相対湿度が決まれば含水率が 1 つに決まる）。
6. 空気の圧力は一定で、材料の中を空気は流れない（通気層の換気は別に扱う）。
7. 液水の流れのうち、温度差による流れと重力による流れは扱わない（重力は、水平方向に流れる壁では効かない）。
8. 熱伝導率は含水率によらない一定値とする。
9. 蒸発潜熱は温度によらない一定値とする。

## 3 状態量

未知数は、各点の温度と水分化学ポテンシャルの 2 つとし、ほかの量はこの 2 つから決める。水分化学ポテンシャルは、自由水面（相対湿度 100%）を 0 とし、それより乾いた状態では負になる。

相対湿度は、式 {eq}`be-rh` で表される（「{doc}`湿り空気と水の性質 <03_02_eval_air_water>`」の式 (3)）。

$$
\varphi = 100 \exp \left( \frac{\mu}{R_{\mathrm{v}} T} \right)
$$ (be-rh)

ここで、

:::{container} symbols
$\varphi$
: ：相対湿度（%）

$\mu$
: ：水分化学ポテンシャル（J/kg）

$R_{\mathrm{v}}$
: ：水蒸気の気体定数（J/(kg K)）

$T$
: ：温度（K）
:::

である。水蒸気圧と水蒸気の密度は、式 {eq}`be-pv` と式 {eq}`be-rhov` で表される（「{doc}`湿り空気と水の性質 <03_02_eval_air_water>`」の式 (4)・(5)）。

$$
p_{\mathrm{v}} = \frac{\varphi}{100} \thinspace p_{\mathrm{vs}}(T)
$$ (be-pv)

$$
\rho_{\mathrm{v}} = \frac{p_{\mathrm{v}}}{R_{\mathrm{v}} T}
$$ (be-rhov)

ここで、

:::{container} symbols
$p_{\mathrm{v}}$
: ：水蒸気圧（Pa）

$\varphi$
: ：相対湿度（%）

$p_{\mathrm{vs}}(T)$
: ：温度 $T$ の飽和水蒸気圧（Pa）

$\rho_{\mathrm{v}}$
: ：水蒸気の密度（kg/m³）

$R_{\mathrm{v}}$
: ：水蒸気の気体定数（J/(kg K)）

$T$
: ：温度（K）
:::

である。材料の含水量は、式 {eq}`be-w` で表される。

$$
w = \rho_{\mathrm{s}} \thinspace u(\varphi) = \rho_{\mathrm{w}} \psi
$$ (be-w)

ここで、

:::{container} symbols
$w$
: ：容積あたりの含水量（kg/m³）

$\rho_{\mathrm{s}}$
: ：材料の乾燥密度（kg/m³）

$u(\varphi)$
: ：相対湿度 $\varphi$ の平衡含水率（質量含水率）（kg/kg）

$\rho_{\mathrm{w}}$
: ：水の密度（kg/m³）

$\psi$
: ：容積含水率（m³/m³）
:::

である。

## 4 流れの式

外気側から室内側へ向かう向きに位置の座標をとり、その向きを流れの正とする。

熱伝導は、式 {eq}`be-q` で表される。

$$
q = - \lambda_{\mathrm{h}} \frac{\partial T}{\partial x}
$$ (be-q)

ここで、

:::{container} symbols
$q$
: ：熱伝導による熱の流れ（W/m²）

$\lambda_{\mathrm{h}}$
: ：熱伝導率（W/(m K)）

$T$
: ：温度（K）

$x$
: ：壁の厚さの方向の位置（m）
:::

である。水蒸気は水蒸気圧の勾配で、液水は水分化学ポテンシャルの勾配で流れるとし、それぞれ式 {eq}`be-jv` と式 {eq}`be-jl` で表す。

$$
J_{\mathrm{v}} = - \lambda'_{\mathrm{m}} \frac{\partial p_{\mathrm{v}}}{\partial x}
$$ (be-jv)

$$
J_{\mathrm{l}} = - \lambda'_{\mu \mathrm{l}} \frac{\partial \mu}{\partial x}
$$ (be-jl)

ここで、

:::{container} symbols
$J_{\mathrm{v}}$
: ：水蒸気の流れ（kg/(m² s)）

$\lambda'_{\mathrm{m}}$
: ：湿気伝導率。相対湿度によって変わる（kg/(m s Pa)）

$p_{\mathrm{v}}$
: ：水蒸気圧（Pa）

$J_{\mathrm{l}}$
: ：液水の流れ（kg/(m² s)）

$\lambda'_{\mu \mathrm{l}}$
: ：液相水分伝導率（kg/(m s (J/kg))）

$\mu$
: ：水分化学ポテンシャル（J/kg）

$x$
: ：壁の厚さの方向の位置（m）
:::

である。液相水分伝導率と液水拡散係数の関係は、「{doc}`材料の性質の扱い <04_02_basis_materials>`」の 2 節に示す。

## 5 収支の式の導き方

「たまる量の変化 ＝ 正味で入ってくる量 ＋ 発生する量」を、液水・水蒸気・エネルギー（エンタルピー）のそれぞれについて書く（参考文献 [1]）。

### 5.1 水分の収支

液水と水蒸気の収支は、式 {eq}`be-bal-l` と式 {eq}`be-bal-v` で表される。水蒸気は、空隙のうち液水で満たされていない部分にある。

$$
\frac{\partial \left( \rho_{\mathrm{w}} \psi \right)}{\partial t} = - \frac{\partial J_{\mathrm{l}}}{\partial x} + W
$$ (be-bal-l)

$$
\frac{\partial \left\lbrace \left( \Phi_0 - \psi \right) \rho_{\mathrm{v}} \right\rbrace}{\partial t} = - \frac{\partial J_{\mathrm{v}}}{\partial x} - W
$$ (be-bal-v)

ここで、

:::{container} symbols
$\rho_{\mathrm{w}}$
: ：水の密度（kg/m³）

$\psi$
: ：容積含水率（m³/m³）

$t$
: ：時間（s）

$J_{\mathrm{l}}$
: ：液水の流れ（kg/(m² s)）

$J_{\mathrm{v}}$
: ：水蒸気の流れ（kg/(m² s)）

$x$
: ：壁の厚さの方向の位置（m）

$W$
: ：水蒸気が液水になる量（相変化の量）。水蒸気が液水になる向きを正とする（kg/(m³ s)）

$\Phi_0$
: ：乾燥時の空隙率（m³/m³）

$\rho_{\mathrm{v}}$
: ：水蒸気の密度（kg/m³）
:::

である。2 つを足すと、相変化の量が消えて、式 {eq}`be-bal-m` の水分の収支になる。

$$
\frac{\partial}{\partial t} \left\lbrace \rho_{\mathrm{w}} \psi + \left( \Phi_0 - \psi \right) \rho_{\mathrm{v}} \right\rbrace = - \frac{\partial}{\partial x} \left( J_{\mathrm{v}} + J_{\mathrm{l}} \right)
$$ (be-bal-m)

ここで、

:::{container} symbols
$\rho_{\mathrm{w}}$
: ：水の密度（kg/m³）

$\psi$
: ：容積含水率（m³/m³）

$\Phi_0$
: ：乾燥時の空隙率（m³/m³）

$\rho_{\mathrm{v}}$
: ：水蒸気の密度（kg/m³）

$t$
: ：時間（s）

$J_{\mathrm{v}}$
: ：水蒸気の流れ（kg/(m² s)）

$J_{\mathrm{l}}$
: ：液水の流れ（kg/(m² s)）

$x$
: ：壁の厚さの方向の位置（m）
:::

である。

### 5.2 熱の収支

材料の実質部・液水・水蒸気のエンタルピーの収支を書き、式 {eq}`be-bal-l` と式 {eq}`be-bal-v` を使って整理すると、式 {eq}`be-bal-h` になる（参考文献 [1]）。

$$
c \rho \thinspace \frac{\partial T}{\partial t} = - \frac{\partial q}{\partial x} + L_{\mathrm{v}} W
$$ (be-bal-h)

$$
c \rho = c_{\mathrm{s}} \rho_{\mathrm{s}} + c_{\mathrm{w}} \rho_{\mathrm{w}} \psi + c_{\mathrm{vap}} \rho_{\mathrm{v}} \left( \Phi_0 - \psi \right)
$$ (be-crho)

ここで、

:::{container} symbols
$c \rho$
: ：水分を含んだ材料のみかけの容積比熱（J/(m³ K)）

$T$
: ：温度（K）

$t$
: ：時間（s）

$q$
: ：熱伝導による熱の流れ（W/m²）

$x$
: ：壁の厚さの方向の位置（m）

$L_{\mathrm{v}}$
: ：水の蒸発潜熱（J/kg）

$W$
: ：水蒸気が液水になる量（kg/(m³ s)）

$c_{\mathrm{s}}$
: ：材料の実質部の比熱（J/(kg K)）

$\rho_{\mathrm{s}}$
: ：材料の乾燥密度（kg/m³）

$c_{\mathrm{w}}$
: ：水の比熱（J/(kg K)）

$\rho_{\mathrm{w}}$
: ：水の密度（kg/m³）

$\psi$
: ：容積含水率（m³/m³）

$c_{\mathrm{vap}}$
: ：水蒸気の比熱（J/(kg K)）

$\rho_{\mathrm{v}}$
: ：水蒸気の密度（kg/m³）

$\Phi_0$
: ：乾燥時の空隙率（m³/m³）
:::

である。整理の途中で、水分の流れが運ぶ顕熱の項（水蒸気と液水の流れに、それぞれの比熱と温度の勾配を掛けた項）が出てくるが、量が非常に小さいので省く。

### 5.3 近似

#### 5.3.1 空隙にたまる水蒸気の量の変化を省く

水蒸気の収支（式 {eq}`be-bal-v`）の左辺、すなわち空隙にたまる水蒸気の量の変化を省く。すると、相変化の量は、水蒸気の正味の流入だけで表され、式 {eq}`be-w-approx` になる。

$$
W = - \frac{\partial J_{\mathrm{v}}}{\partial x}
$$ (be-w-approx)

ここで、

:::{container} symbols
$W$
: ：水蒸気が液水になる量（kg/(m³ s)）

$J_{\mathrm{v}}$
: ：水蒸気の流れ（kg/(m² s)）

$x$
: ：壁の厚さの方向の位置（m）
:::

である。これを式 {eq}`be-bal-h` に入れると、相変化の熱は、水蒸気が運ぶ潜熱の流れの発散になる。

$$
c \rho \thinspace \frac{\partial T}{\partial t} = - \frac{\partial}{\partial x} \left( q + L_{\mathrm{v}} J_{\mathrm{v}} \right)
$$ (be-bal-h2)

ここで、

:::{container} symbols
$c \rho$
: ：水分を含んだ材料のみかけの容積比熱（J/(m³ K)）

$T$
: ：温度（K）

$t$
: ：時間（s）

$q$
: ：熱伝導による熱の流れ（W/m²）

$L_{\mathrm{v}}$
: ：水の蒸発潜熱（J/kg）

$J_{\mathrm{v}}$
: ：水蒸気の流れ（kg/(m² s)）

$x$
: ：壁の厚さの方向の位置（m）
:::

である。

水分の収支（式 {eq}`be-bal-m`）は、液水の収支と水蒸気の収支を足したものなので、つじつまを合わせるため、式 {eq}`be-bal-m` の左辺からも、同じ水蒸気の分を省く。すると、たまる水分は液水だけになり、水分の収支は式 {eq}`be-bal-m2` になる。

$$
\frac{\partial \left( \rho_{\mathrm{w}} \psi \right)}{\partial t} = - \frac{\partial}{\partial x} \left( J_{\mathrm{v}} + J_{\mathrm{l}} \right)
$$ (be-bal-m2)

ここで、

:::{container} symbols
$\rho_{\mathrm{w}}$
: ：水の密度（kg/m³）

$\psi$
: ：容積含水率（m³/m³）

$t$
: ：時間（s）

$J_{\mathrm{v}}$
: ：水蒸気の流れ（kg/(m² s)）

$J_{\mathrm{l}}$
: ：液水の流れ（kg/(m² s)）

$x$
: ：壁の厚さの方向の位置（m）
:::

である。

通気層の空気には、この近似を使わない（9 節）。

#### 5.3.2 近似の目的

前提 3（局所平衡）により、液水と水蒸気は常に平衡しているので、相変化の量には、それ自体を決める式がない。そのため、相変化の量は、収支の式から消す必要がある。この近似は、相変化の量を、式 {eq}`be-w-approx` の簡単な形で表すためのものである。

近似をしなくても、相変化の量は消せる。水蒸気の収支（式 {eq}`be-bal-v`）をそのまま変形すると、式 {eq}`be-w-full` になる。

$$
W = - \frac{\partial J_{\mathrm{v}}}{\partial x} - \frac{\partial \left\lbrace \left( \Phi_0 - \psi \right) \rho_{\mathrm{v}} \right\rbrace}{\partial t}
$$ (be-w-full)

ここで、

:::{container} symbols
$W$
: ：水蒸気が液水になる量（kg/(m³ s)）

$J_{\mathrm{v}}$
: ：水蒸気の流れ（kg/(m² s)）

$x$
: ：壁の厚さの方向の位置（m）

$\Phi_0$
: ：乾燥時の空隙率（m³/m³）

$\psi$
: ：容積含水率（m³/m³）

$\rho_{\mathrm{v}}$
: ：水蒸気の密度（kg/m³）

$t$
: ：時間（s）
:::

である。これを式 {eq}`be-bal-h` に入れると、熱の収支は式 {eq}`be-bal-h-full` になる。

$$
c \rho \thinspace \frac{\partial T}{\partial t} + L_{\mathrm{v}} \frac{\partial \left\lbrace \left( \Phi_0 - \psi \right) \rho_{\mathrm{v}} \right\rbrace}{\partial t} = - \frac{\partial}{\partial x} \left( q + L_{\mathrm{v}} J_{\mathrm{v}} \right)
$$ (be-bal-h-full)

ここで、

:::{container} symbols
$c \rho$
: ：水分を含んだ材料のみかけの容積比熱（J/(m³ K)）

$T$
: ：温度（K）

$t$
: ：時間（s）

$L_{\mathrm{v}}$
: ：水の蒸発潜熱（J/kg）

$\Phi_0$
: ：乾燥時の空隙率（m³/m³）

$\psi$
: ：容積含水率（m³/m³）

$\rho_{\mathrm{v}}$
: ：水蒸気の密度（kg/m³）

$x$
: ：壁の厚さの方向の位置（m）

$q$
: ：熱伝導による熱の流れ（W/m²）

$J_{\mathrm{v}}$
: ：水蒸気の流れ（kg/(m² s)）
:::

である。式 {eq}`be-bal-h2` と比べると、左辺に、空隙の水蒸気が増える・減るときの潜熱の項が残る。空隙の水蒸気の量は、温度と水分化学ポテンシャルの両方で決まるので、この項は、温度の時間の変化だけでなく、水分化学ポテンシャルの時間の変化も含む。水分の収支も、式 {eq}`be-bal-m` のまま、空隙の水蒸気の量が残る。

そのため、この近似は、計算をできるようにするための近似ではない。近似のメリットは、次の 3 つである。

1. 水分の容量が、平衡含水率の曲線だけで決まる。近似をしないと、材料の性質として、空隙率も必要になる。
2. 熱の収支の式が簡単になる。たまる熱は顕熱だけになり、相変化の熱は水蒸気が運ぶ潜熱の流れの差だけで書ける。近似をしないと、空隙の水蒸気の潜熱の項が、温度と水分化学ポテンシャルの両方の時間の変化で決まり、熱と水分のつながりが 1 つ増える。
3. 広く使われているモデルと同じ形になる。たまる水分を平衡含水率の曲線で表し、熱の収支に水蒸気の流れの潜熱を入れる形は、建物の壁の熱・水分の計算でよく使われている（参考文献 [2]）。同じ形なので、ほかのプログラムの結果と比べやすく、材料のデータもその形のまま使える。

一方、近似をしない場合も、離散化すると、水分の収支と熱の収支に「ステップの初めと終わりの空隙の水蒸気の量の差」の項を 1 つずつ足すだけで、熱と水分の保存性も崩れない。計算の難しさは、ほとんど変わらない。

#### 5.3.3 近似の影響の確かめ

この近似がどのくらい効くかを、次の 3 つの段階で確かめた。

(1) 密度の比べ

飽和した水蒸気の密度は、液水の密度（998 kg/m³）よりずっと小さい（表 1）。

表 1　飽和した水蒸気の密度と液水の密度の比

| 温度 | 飽和水蒸気圧 | 飽和した水蒸気の密度 | 液水の密度との比 |
|---|---|---|---|
| 0 deg.C | 611 Pa | 0.0049 kg/m³ | 約 1/200,000 |
| 20 deg.C | 2339 Pa | 0.017 kg/m³ | 約 1/58,000 |
| 40 deg.C | 7385 Pa | 0.051 kg/m³ | 約 1/20,000 |

(2) 材料の体積あたりの、たまる量の比べ

ただし、収支の式でたまる量になるのは、密度そのものではなく、材料の体積あたりの液水の量と、空隙にある水蒸気の量である。そこで、温度 20 deg.C で相対湿度が 40% から 60% に変わるときに増える量を、1% あたりで比べた（表 2）。空隙率は 1 を超えないので、空隙率を 1 として、水蒸気の分を大きめに見積もった。

表 2　相対湿度 1% あたりに増える液水の量と水蒸気の量の比（温度 20 deg.C、相対湿度 40〜60%、空隙率 1）

| 材料 | 液水の増え方 ÷ 水蒸気の増え方 |
|---|---|
| Whamcavity の材料（17 種）の中央値 | 約 2,100 |
| MEWS・ASHRAE の材料（67 種）の中央値 | 約 4,000 |
| Whamcavity のグラスウール（乾燥密度 16 kg/m³） | 約 4 |
| ASHRAE Low-density Glassfibre Batt Insulation（乾燥密度 11.5 kg/m³） | 約 4 |
| Whamcavity の発泡プラスチック（乾燥密度 30〜40 kg/m³） | 約 7〜10 |
| Whamcavity のセルロースファイバー | 約 9 |
| ASHRAE Extruded Polystyrene Insulation | 約 60 |

中央値には、空気と、相対湿度 40〜60% で平衡含水率が変わらないとされている材料（MEWS の防水・透湿シートなど 13 種と、乾燥密度が 0 で読み込まれる Whamcavity のシージング）を含めていない。

多くの材料では、水蒸気の分は液水の分の 1/1000 程度で、省いても問題ない。一方、密度の小さい断熱材では、水蒸気の分が液水の分の 1/4〜1/10 あり、省くと、その層の水分の容量を 10〜20% 小さく見積もる。

(3) 年間の計算での影響

密度の小さい断熱材で省いた影響を、年間の計算で確かめた。壁は、外側からサイディング・通気層・せっこうボード・構造用合板・グラスウール（厚さ 100 mm）・構造用合板・せっこうボードの 7 層で、気象データ（1 時間ごと）と室内の条件（室温の年平均 22.5 deg.C、相対湿度 60%）で 2 年間計算し、2 年目を比べた（時間刻み 3600 s）。近似をしない計算では、5.3.2 で述べたとおり、水分の収支と熱の収支に、ステップの初めと終わりの空隙の水蒸気の量の差の項を足した。グラスウールの空隙率 0.99 は、乾燥密度（16 kg/m³）とガラスの密度（約 2500 kg/m³）から見積もった値である。

差が大きいのは、グラスウールの層と、その外側の合板のグラスウール側だけで、グラスウールの室内側ほど大きい。すべての材料の層で近似をしなくても、グラスウールの層だけの場合とほとんど変わらないので、差のほとんどはグラスウールの層の近似によるものである。温度の差は、すべての質点で最大 0.04 K、平均 0.004 K であった。

相対湿度の差がもっとも大きいのは、グラスウールの室内側の端の質点で、2 年目の最高の相対湿度は、近似をした計算で 83.9%、近似をしない計算で 83.5% であった。近似をしないと、グラスウールの水分の容量が大きくなるので、相対湿度の変化が少しゆるやかになる。年平均の相対湿度の差は、どの質点でも 0.05% 以下であった。ニュートン法の修正の回数は変わらなかった。

#### 5.3.4 検討の結果

近似による差は、材料の性質の測定の精度より十分小さい。そのため、5.3.2 のメリットをとって、この近似を使う。ただし、密度の小さい断熱材の層で、相対湿度の短い時間の変化を細かく見るときは、この近似で変化がわずかに大きめになることに注意する。

近似をやめる場合は、次のことが必要になる。

- 材料の性質に、乾燥時の空隙率を加える（乾燥密度と、材料の実質部の密度から見積もることもできる）。
- 質点の水分量に、空隙の水蒸気の量を加える。
- 凝縮熱を、水蒸気の正味の流入から、空隙にたまる水蒸気の量の変化を引いた量で求める（式 {eq}`be-w-full`）。

#### 5.3.5 水蒸気の熱容量を省く

これとは別に、みかけの容積比熱（式 {eq}`be-crho`）の第 3 項、すなわち空隙の水蒸気の熱容量を省く。熱容量の差がもっとも小さいグラスウールでも、空隙の水蒸気の熱容量は、乾燥した材料の熱容量の 0.4% であり、どの材料でも無視できる。

## 6 最終的に使う式

式 {eq}`be-bal-m2` と式 {eq}`be-bal-h2` に、流れの式 {eq}`be-q`〜{eq}`be-jl` を入れると、水分の収支と熱の収支は、式 {eq}`be-final-m` と式 {eq}`be-final-h` になる。

$$
\frac{\partial w}{\partial t} = \frac{\partial}{\partial x} \left( \lambda'_{\mathrm{m}} \frac{\partial p_{\mathrm{v}}}{\partial x} + \lambda'_{\mu \mathrm{l}} \frac{\partial \mu}{\partial x} \right)
$$ (be-final-m)

$$
\left( c_{\mathrm{s}} \rho_{\mathrm{s}} + c_{\mathrm{w}} w \right) \frac{\partial T}{\partial t} = \frac{\partial}{\partial x} \left( \lambda_{\mathrm{h}} \frac{\partial T}{\partial x} + L_{\mathrm{v}} \lambda'_{\mathrm{m}} \frac{\partial p_{\mathrm{v}}}{\partial x} \right)
$$ (be-final-h)

ここで、

:::{container} symbols
$w$
: ：容積あたりの含水量（kg/m³）

$t$
: ：時間（s）

$x$
: ：壁の厚さの方向の位置（m）

$\lambda'_{\mathrm{m}}$
: ：湿気伝導率（kg/(m s Pa)）

$p_{\mathrm{v}}$
: ：水蒸気圧（Pa）

$\lambda'_{\mu \mathrm{l}}$
: ：液相水分伝導率（kg/(m s (J/kg))）

$\mu$
: ：水分化学ポテンシャル（J/kg）

$c_{\mathrm{s}}$
: ：材料の実質部の比熱（J/(kg K)）

$\rho_{\mathrm{s}}$
: ：材料の乾燥密度（kg/m³）

$c_{\mathrm{w}}$
: ：水の比熱（J/(kg K)）

$T$
: ：温度（K）

$\lambda_{\mathrm{h}}$
: ：熱伝導率（W/(m K)）

$L_{\mathrm{v}}$
: ：水の蒸発潜熱（J/kg）
:::

である。通気層の空気の収支は、9 節に示す。

## 7 水蒸気の流れを水蒸気圧の差のまま使う理由

熱・水分同時移動の式は、水蒸気圧の勾配を、温度の勾配と水分化学ポテンシャルの勾配に分けた形で書かれることも多い。式 {eq}`be-split` のように分けると、式 {eq}`be-lambda-g` の 2 つの係数を使った形になる。

$$
\frac{\partial p_{\mathrm{v}}}{\partial x} = \left( \frac{\partial p_{\mathrm{v}}}{\partial \mu} \right)_T \frac{\partial \mu}{\partial x} + \left( \frac{\partial p_{\mathrm{v}}}{\partial T} \right)_\mu \frac{\partial T}{\partial x}
$$ (be-split)

$$
\lambda'_{\mu \mathrm{g}} = \lambda'_{\mathrm{m}} \left( \frac{\partial p_{\mathrm{v}}}{\partial \mu} \right)_T, \quad
\lambda'_{T \mathrm{g}} = \lambda'_{\mathrm{m}} \left( \frac{\partial p_{\mathrm{v}}}{\partial T} \right)_\mu
$$ (be-lambda-g)

ここで、

:::{container} symbols
$p_{\mathrm{v}}$
: ：水蒸気圧（Pa）

$x$
: ：壁の厚さの方向の位置（m）

$\mu$
: ：水分化学ポテンシャル（J/kg）

$T$
: ：温度（K）

$\lambda'_{\mu \mathrm{g}}$
: ：水分化学ポテンシャルの勾配に対する気相水分伝導率（kg/(m s (J/kg))）

$\lambda'_{T \mathrm{g}}$
: ：温度の勾配に対する気相水分伝導率（kg/(m s K)）

$\lambda'_{\mathrm{m}}$
: ：湿気伝導率（kg/(m s Pa)）
:::

である。

連続の式としては同じだが、離散化したときの扱いが違う。分けた形では、隣り合う質点の水蒸気圧の差を、偏微分を使った 1 次の近似で表すことになる。隣どうしの温度や湿度の差が大きい所（防湿層の両側、断熱材の両側、結露しかけている所など）では、その近似の誤差が答えに残る。

このプログラムでは、分けずに水蒸気圧の差のまま使う（「{doc}`熱・水分の流れ <03_05_eval_flows>`」の式 (10)）。偏微分は、ニュートン法で修正の向きを求めるとき（ヤコビ行列）だけに使い、答えには入らない。

## 8 表面の境界

表面と空気の間の流れは、伝達率で表す。

$$
q_{\mathrm{s}} = \alpha \left( T_{\mathrm{a}} - T_{\mathrm{s}} \right), \quad
J_{\mathrm{v,s}} = \alpha'_{\mathrm{p}} \left( p_{\mathrm{v,a}} - p_{\mathrm{v,s}} \right)
$$ (be-surface)

ここで、

:::{container} symbols
$q_{\mathrm{s}}$
: ：空気から表面への熱の流れ（W/m²）

$\alpha$
: ：総合熱伝達率（W/(m² K)）

$T_{\mathrm{a}}$
: ：空気の温度（K）

$T_{\mathrm{s}}$
: ：表面の温度（K）

$J_{\mathrm{v,s}}$
: ：空気から表面への水蒸気の流れ（kg/(m² s)）

$\alpha'_{\mathrm{p}}$
: ：湿気伝達率（kg/(m² s Pa)）

$p_{\mathrm{v,a}}$
: ：空気の水蒸気圧（Pa）

$p_{\mathrm{v,s}}$
: ：表面の水蒸気圧（Pa）
:::

である。

- 総合熱伝達率と湿気伝達率は、「{doc}`熱・水分の流れ <03_05_eval_flows>`」の境目の熱コンダクタンスと湿気コンダクタンスとして与える。
- 空気と表面の間では、液水は移動しない（雨は扱わない）。
- 表面のエンタルピーの収支から、表面を通る熱の流れには、水蒸気が運ぶ潜熱も入る。これは、式 {eq}`be-bal-h2` の「熱伝導 ＋ 潜熱の流れ」と同じ形である。
- 日射・夜間放射による熱は、外表面の質点に入る熱として足す（「{doc}`外表面の日射・夜間放射 <03_09_eval_surface_solar>`」）。

## 9 通気層の空気の収支

通気層の空気には、液水がなく、空隙がすべて空気である。そのため、5 節の材料の式を、次のように変える。

- 液水の収支（式 {eq}`be-bal-l`）はない。相変化も起きないので、相変化の量は 0 とする。
- 通気層の空気は、壁の厚さの方向と直交する向きに換気され、外気と入れ替わる。壁の厚さの方向の 1 次元の式では、換気で入る水分と熱を、体積あたりの発生する量として扱う。換気量の求め方は、「{doc}`通気層の換気 <03_10_eval_ventilation>`」に示す。
- 5.3 節の近似は使わない。たまる水分は、水蒸気だけになる。
- 通気層の空気と両側の材料の表面の間の熱と水蒸気の流れは、8 節の伝達率で表す。

水分の収支は、水蒸気の収支（式 {eq}`be-bal-v`）で、乾燥時の空隙率を 1、容積含水率を 0、相変化の量を 0 とし、換気で入る水分を加えて、式 {eq}`be-air-m` になる。

$$
\frac{\partial \rho_{\mathrm{v}}}{\partial t} = - \frac{\partial J_{\mathrm{v}}}{\partial x} + a_{\mathrm{vent}} \left( \rho_{\mathrm{v,ex}} - \rho_{\mathrm{v}} \right)
$$ (be-air-m)

ここで、

:::{container} symbols
$\rho_{\mathrm{v}}$
: ：通気層の空気の水蒸気の密度（kg/m³）

$t$
: ：時間（s）

$J_{\mathrm{v}}$
: ：水蒸気の流れ（kg/(m² s)）

$x$
: ：壁の厚さの方向の位置（m）

$a_{\mathrm{vent}}$
: ：通気層の空気の体積あたりの換気量（m³/(m³ s)）

$\rho_{\mathrm{v,ex}}$
: ：外気の水蒸気の密度（kg/m³）
:::

である。壁 1 m² あたりの換気量（「{doc}`通気層の換気 <03_10_eval_ventilation>`」）は、体積あたりの換気量に、通気層の空気の質点のコントロールボリュームの幅を掛けたものである。

熱の収支は、式 {eq}`be-bal-h` で、相変化の量を 0 とし、換気で入る熱を加えて、式 {eq}`be-air-h-full` になる。

$$
\left( c_{\mathrm{a}} \rho_{\mathrm{a}} + c_{\mathrm{vap}} \rho_{\mathrm{v}} \right) \frac{\partial T}{\partial t} = - \frac{\partial q}{\partial x} + \left( c_{\mathrm{a}} \rho_{\mathrm{a,ex}} + c_{\mathrm{vap}} \rho_{\mathrm{v,ex}} \right) a_{\mathrm{vent}} \left( T_{\mathrm{ex}} - T \right)
$$ (be-air-h-full)

ここで、

:::{container} symbols
$c_{\mathrm{a}}$
: ：空気の比熱（J/(kg K)）

$\rho_{\mathrm{a}}$
: ：通気層の空気の密度（kg/m³）

$c_{\mathrm{vap}}$
: ：水蒸気の比熱（J/(kg K)）

$\rho_{\mathrm{v}}$
: ：通気層の空気の水蒸気の密度（kg/m³）

$T$
: ：通気層の空気の温度（K）

$t$
: ：時間（s）

$q$
: ：熱伝導による熱の流れ（W/m²）

$x$
: ：壁の厚さの方向の位置（m）

$\rho_{\mathrm{a,ex}}$
: ：外気の密度（kg/m³）

$\rho_{\mathrm{v,ex}}$
: ：外気の水蒸気の密度（kg/m³）

$a_{\mathrm{vent}}$
: ：通気層の空気の体積あたりの換気量（m³/(m³ s)）

$T_{\mathrm{ex}}$
: ：外気の温度（K）
:::

である。相変化が起きないので、材料の式 {eq}`be-bal-h2` と違い、水蒸気の流れが運ぶ潜熱の項はない。

式 {eq}`be-air-h-full` の水蒸気の分（左辺の水蒸気の熱容量と、換気で入る水蒸気の顕熱）は省く。水蒸気の比熱を約 1.9 kJ/(kg K) とすると、飽和した水蒸気の熱容量は、空気の熱容量の約 2.7%（20 deg.C）〜約 8.4%（40 deg.C）である。ただし、通気層の空気の熱容量そのものが壁の中でごく小さい。厚さ 25 mm の通気層の空気の熱容量は、壁 1 m² あたり約 30 J/K で、厚さ 16 mm のサイディングの約 15,000 J/K の 0.2% である。そのため、水蒸気の分を省いても、壁の温度にはほとんど影響しない。省くと、熱の収支は式 {eq}`be-air-h` になる。

$$
c_{\mathrm{a}} \rho_{\mathrm{a}} \thinspace \frac{\partial T}{\partial t} = - \frac{\partial q}{\partial x} + c_{\mathrm{a}} \rho_{\mathrm{a,ex}} \thinspace a_{\mathrm{vent}} \left( T_{\mathrm{ex}} - T \right)
$$ (be-air-h)

ここで、

:::{container} symbols
$c_{\mathrm{a}}$
: ：空気の比熱（J/(kg K)）

$\rho_{\mathrm{a}}$
: ：通気層の空気の密度（kg/m³）

$T$
: ：通気層の空気の温度（K）

$t$
: ：時間（s）

$q$
: ：熱伝導による熱の流れ（W/m²）

$x$
: ：壁の厚さの方向の位置（m）

$\rho_{\mathrm{a,ex}}$
: ：外気の密度（kg/m³）

$a_{\mathrm{vent}}$
: ：通気層の空気の体積あたりの換気量（m³/(m³ s)）

$T_{\mathrm{ex}}$
: ：外気の温度（K）
:::

である。

## 10 質点ごとの式への離散化

### 10.1 コントロールボリュームで収支をとる

壁を質点に分け、各質点が受け持つ範囲（コントロールボリューム）で、式 {eq}`be-final-m` と式 {eq}`be-final-h` を積分する（有限体積法）。たまる量はコントロールボリュームの中の量の変化、流れはコントロールボリュームの両端を通る量になる。入ってきた量は隣のコントロールボリュームから出ていった量と同じなので、壁全体で、熱と水分が離散化の後も保存される。

### 10.2 抵抗を直列に足す

隣り合う 2 つの質点の間の流れは、質点からコントロールボリュームの端までの抵抗と、端（境目）の抵抗の和で表す（「{doc}`熱・水分の流れ <03_05_eval_flows>`」の式 (6)〜(8)）。熱を例にとると、式 {eq}`be-series` になる。

$$
q = \frac{T_{\mathrm{L}} - T_{\mathrm{R}}}{d_{\mathrm{L}} / \lambda_{\mathrm{h,L}} + 1 / G_{\mathrm{h}} + d_{\mathrm{R}} / \lambda_{\mathrm{h,R}}}
$$ (be-series)

ここで、

:::{container} symbols
$q$
: ：2 つの質点の間の熱の流れ（W/m²）

$T_{\mathrm{L}}$
: ：左の質点の温度（K）

$T_{\mathrm{R}}$
: ：右の質点の温度（K）

$d_{\mathrm{L}}$
: ：左の質点から境目までの距離（m）

$\lambda_{\mathrm{h,L}}$
: ：左の質点の材料の熱伝導率（W/(m K)）

$G_{\mathrm{h}}$
: ：境目の熱コンダクタンス（W/(m² K)）

$d_{\mathrm{R}}$
: ：右の質点から境目までの距離（m）

$\lambda_{\mathrm{h,R}}$
: ：右の質点の材料の熱伝導率（W/(m K)）
:::

である。これは、左の質点から境目まで、境目、境目から右の質点までの 3 つの部分を同じ量の熱が流れる（境目に熱がたまらない）として、境目の両側の温度を消去したものである。材料の性質が異なる層の境目でも、流れが連続するので、熱・水分が保存される。水蒸気・液水も同じ形にする。

湿気伝導率と液相水分伝導率は、それぞれの側の質点の状態で求める。境目の左右で材料が違っても、その材料の値で抵抗を計算できる。

### 10.3 時間は後退差分にする

時間は、流れと外から入る熱・水分を、ステップの終わりの値で計算する後退差分（完全陰解法）にした（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の式 (8)・(9)）。理由は次のとおりである。

- 時間刻みをどれだけ大きくしても、解が振動したり発散したりしない。薄い層や通気層の空気のように熱容量が小さい質点があっても、時間刻みをその質点に合わせて小さくしなくてよい。前進差分（陽解法）では、熱容量が小さい質点に合わせて時間刻みを非常に小さくしなければならない。
- その代わり、1 ステップごとに非線形の連立方程式を解く必要がある。これは、ニュートン法で解く（「{doc}`1 ステップの解き方 <03_12_eval_solve>`」）。
- 時間についての精度は 1 次である。1 時間ごとの気象データで、1 時間程度の時間刻みで計算する用途には、十分と考えた。

### 10.4 たまる水分を水分量の差で書く

水分の収支のたまる量は、水分容量（含水量の水分化学ポテンシャルによる微分）と水分化学ポテンシャルの変化の積ではなく、水分量そのものの差で書く（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の式 (8)）。水分容量で書くと、平衡含水率の曲線を直線で近似することになり、1 ステップの水分化学ポテンシャルの変化が大きいと、水分が保存されなくなる。水分量の差で書けば、ニュートン法が収束した答えでは、水分量が厳密に保存される。

熱容量は、ステップの終わりの含水量で計算する。熱の収支は、熱容量と温度の変化の積で書くので、熱容量が 1 ステップの中で変わる分だけ、熱は厳密には保存されない。熱容量の変化は含まれる水の分だけで、1 ステップの中では小さい。

### 10.5 凝縮熱の求め方

質点の凝縮熱は、5.3 節の近似（式 {eq}`be-w-approx`）をコントロールボリュームに当てはめ、入ってくる水蒸気から出ていく水蒸気を引いた量に、蒸発潜熱を掛けて求める（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の式 (7)）。

通気層の空気の質点では、凝縮熱を数えない。空気の質点では、たまる水分はすべて水蒸気のままで、相変化は起きない。材料と同じ近似を使うと、換気で入った水蒸気がつながりから出ていくとき、通気層で蒸発したと見積もってしまう。
