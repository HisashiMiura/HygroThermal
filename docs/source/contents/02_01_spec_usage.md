# 使い方

## 1 必要なもの

- Python 3.11 以上
- numpy、pandas、scipy、openpyxl、h5py

リポジトリの一番上のフォルダで、次のように入れる。必要なライブラリも一緒に入る。

```
pip install -e .
```

テストを動かすときは `pip install -e ".[dev]"`、この文書のサイトを作るときは `pip install -e ".[docs]"` とする。

## 2 計算のしかた

入力のファイル（「{doc}`入力のファイル <02_02_spec_input>`」）を 1 つ用意し、コマンド `hygrothermal` に渡す。

```
hygrothermal case.json
```

結果は、入力のファイルと同じフォルダの `case_output/`（入力のファイルの名前に `_output` を付けたフォルダ）に書き出す。書き出すフォルダは `-o` で指定できる。同じ名前のファイルがあれば、上書きする。

```
hygrothermal case.json -o result/
```

計算の途中経過は、30 日分進むごとと最後に、次のように 1 行ずつ画面（エラーの出力）に出す。`-q` を付けると出さない。

```
30.0 日 / 730 日（4%）、経過 6 秒
```

パッケージを入れずに使うときは、リポジトリの一番上のフォルダで次のようにする。

```
python -m modules.cli case.json
```

例として、7 層の壁（外側から、サイディング、通気層、せっこうボード、構造用合板、グラスウール、構造用合板、せっこうボード）を 2 年間計算する入力のファイル `examples/main_wall.json` がある。時間刻み 3600 s で、計算に 3 分ほどかかる。

```
hygrothermal examples/main_wall.json
```

## 3 終了コード

計算が終わると、表 1 の終了コードを返す。

表 1　終了コード

| 終了コード | 意味 | 書き出すもの |
|---|---|---|
| 0 | 最後まで計算した | 結果のファイル |
| 1 | 途中で計算が止まった（4 節） | 止まるまでの結果のファイル。止まった理由と時刻は画面にも出す |
| 2 | 入力がおかしい、または入力・気象データのファイルが読めない | なし。どの入力がおかしいかを画面に出す |

入力の値は、計算を始める前にすべて確かめる。ただし、緯度・経度・風速の高さなどの外気の値の範囲と、気象データの中身は、気象データを読むときに確かめる。

## 4 計算が止まる理由

計算は、表 2 のいずれかのとき、そのステップで止まる。結果のファイルには、止まる前の最後の記録までを書き出す（「{doc}`結果のファイル <02_04_spec_output>`」）。

表 2　計算が止まる理由

| 理由（画面に出す名前） | 止まるとき |
|---|---|
| 通気層の空気の結露（`Condensation`） | 通気層の空気の質点の相対湿度が、前のステップで 99.9% 以上になり、そのステップが解けなかったとき。通気層の空気の質点は結露した水を持てないので、相対湿度 100% 以下では水分の収支が合わなくなる |
| 空隙が水で満杯（`PoresFilled`） | 空隙率を与えた層で、質点の水分量が、空隙を水で満たす水分量を超えたとき。空隙率を与えない層では起きない |
| 収束しない（`NewtonNotConverged`） | 上の 2 つ以外の理由で、そのステップが解けなかったとき |

どの場合に止めるかは「{doc}`1 ステップの解き方 <03_12_eval_solve>`」の 5 節・6 節に、止める理由は「{doc}`数値解法の安定性 <04_05_basis_solver>`」と「{doc}`材料の中の自由水のモデル <04_07_basis_free_water>`」に示す。

## 5 Python から使う

コマンドと同じ計算を、Python から次のように行える。

```python
from modules import cli

geometry, result, status = cli.run('case.json')
cli.write('case_output', geometry, result, status, 'case.json')
```

`cli.run` は、計算が止まっても例外を出さず、止まるまでの結果と、止まったかどうか（`status.completed`、`status.message`、`status.time_failed`）を返す。

入力をファイルにせず、部品を順に呼んで計算することもできる。手順は次のとおりで、例は `examples/one_year_main_wall.py` にある。

1. 壁の入力 `WallInput.from_dict` から、`build_wall` で壁の形と最初の状態を作る。
2. 気象データ `WeatherOutdoor.from_csv` と、室内の条件 `CosineIndoor` を作る。
3. 経過時間を渡すとその時刻の外気と室内の境界条件 `Boundaries` を返す関数を作り、`simulate` に渡す。

`simulate` は、計算が止まると例外を出す。例外の属性 `partial_result` に止まるまでの結果、`time_failed` に解けなかったステップの終わりの時刻を持つ。
