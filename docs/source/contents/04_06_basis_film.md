## 2 前提

1. 壁の中で水がまとまってたまるのは、層と層の境目（材料と材料の間、材料と通気層の間）とする。境目にたまる水は、材料の空隙に分かれて入る水とは違い、水膜や水滴として表面に留まる。
2. 境目にたまった水は自由水であり、その水分化学ポテンシャルは 0（相対湿度 100%）とする。
3. 水膜には厚さがないものとし、水膜の熱容量は考えない。水膜の温度は、両側との熱のやりとりがつり合う温度とする。
4. 水膜と両側（材料、または通気層の空気）とのやりとりは、水蒸気の流れと熱の流れだけとする。水膜の水が、液水のまま材料に吸い込まれることは扱わない（11 節）。
5. 水膜は、境目の全面を覆うものとする（濡れ面率は 1）。
6. 水膜の水分量が、流れ落ちずに留まれる量を超えた分は、壁の外へ流れ出す（9 節）。
7. 外装材の内側へ浸入した雨水は、指定した境目の水膜に入る（8 節）。

## 3 水膜の質点の収支

### 3.1 水分の収支

図 1 に、材料と通気層の境目の水膜の質点と、その両側のつながりを示す。水膜の質点は、左のつながり（材料の表面と水膜のあいだ。バックシーラーや塗膜などの抵抗）と、右のつながり（水膜と通気層の空気のあいだ。表面の伝達）で、両側の質点とつながる。材料と材料の境目では、右も材料の表面の質点になる。

```{figure} figures/film_series.svg
:alt: 材料の表面の質点と水膜の質点と通気層の空気の質点が、左右のつながりで直列につながる図
:width: 100%

図 1　水膜の質点と、その両側のつながり（材料と通気層の境目の例。境目は厚さがないが、広げて描いている）
```

水膜の水分量の変化は、左のつながりから入ってくる水蒸気と、右のつながりへ出ていく水蒸気の差で決まり、式 {eq}`bf-m` で表される。

$$
\frac{\mathrm{d} W_{\mathrm{f}}}{\mathrm{d} t} = G_{\mathrm{m,L}} \left( p_{\mathrm{v,L}} - p_{\mathrm{v,f}} \right) - G_{\mathrm{m,R}} \left( p_{\mathrm{v,f}} - p_{\mathrm{v,R}} \right)
$$ (bf-m)

ここで、

:::{container} symbols
$W_{\mathrm{f}}$
: ：水膜の水分量（kg/m²）

$t$
: ：時間（s）

$G_{\mathrm{m,L}}$
: ：水膜の左のつながりの湿気コンダクタンス。左の質点から水膜までの抵抗をすべて含めた値の逆数（kg/(m² s Pa)）

$G_{\mathrm{m,R}}$
: ：水膜の右のつながりの湿気コンダクタンス。水膜から右の質点までの抵抗をすべて含めた値の逆数（kg/(m² s Pa)）

$p_{\mathrm{v,L}}$
: ：水膜の左の質点の水蒸気圧（Pa）

$p_{\mathrm{v,R}}$
: ：水膜の右の質点の水蒸気圧（Pa）

$p_{\mathrm{v,f}}$
: ：水膜の質点の水蒸気圧（Pa）
:::

である。

水膜があるとき、水膜の質点の水蒸気圧は、水膜の温度の飽和水蒸気圧である（前提 2）。式 {eq}`bf-m` の右辺が正なら水膜は増え、負なら減る。浸入する雨水と流れ落ちる水があるときは、式 {eq}`bf-m` の右辺に、浸入する雨水を加え、流れ落ちる水を引く（8 節・9 節）。

水膜がないとき、水膜の質点は水分をためない。式 {eq}`bf-m` の左辺は 0 になり、水膜の質点の水蒸気圧は、式 {eq}`bf-pv` のように、両側の水蒸気圧をコンダクタンスで重み付けした値になる。

$$
p_{\mathrm{v,f}} = \frac{G_{\mathrm{m,L}} \thinspace p_{\mathrm{v,L}} + G_{\mathrm{m,R}} \thinspace p_{\mathrm{v,R}}}{G_{\mathrm{m,L}} + G_{\mathrm{m,R}}}
$$ (bf-pv)

ここで、

:::{container} symbols
$p_{\mathrm{v,f}}$
: ：水膜の質点の水蒸気圧（Pa）

$G_{\mathrm{m,L}}$
: ：水膜の左のつながりの湿気コンダクタンス（kg/(m² s Pa)）

$G_{\mathrm{m,R}}$
: ：水膜の右のつながりの湿気コンダクタンス（kg/(m² s Pa)）

$p_{\mathrm{v,L}}$
: ：水膜の左の質点の水蒸気圧（Pa）

$p_{\mathrm{v,R}}$
: ：水膜の右の質点の水蒸気圧（Pa）
:::

である。このとき、水膜の質点を通る水蒸気の流れは、左右のコンダクタンスを直列にした値で流れる。

この 2 つの場合は、離散化した式では、「{doc}`熱・水分の収支 <03_11_eval_balance>`」の水分の収支の式 (8) に、水膜の水分量を水分量として入れた形でまとめて書ける。

### 3.2 熱の収支

水膜の熱容量は 0 なので（前提 3）、熱の収支は、両側のつながりの熱の流れと、水膜での凝縮・蒸発の熱がつり合う式 {eq}`bf-h` になる。

$$
0 = q_{\mathrm{L}} - q_{\mathrm{R}} + L_{\mathrm{v}} \left( j_{\mathrm{v,L}} - j_{\mathrm{v,R}} \right)
$$ (bf-h)

ここで、

:::{container} symbols
$q_{\mathrm{L}}$
: ：水膜の左のつながりから入ってくる熱の流れ（W/m²）

$q_{\mathrm{R}}$
: ：水膜の右のつながりへ出ていく熱の流れ（W/m²）

$L_{\mathrm{v}}$
: ：水の蒸発潜熱（J/kg）

$j_{\mathrm{v,L}}$
: ：水膜の左のつながりから入ってくる水蒸気の流れ（kg/(m² s)）

$j_{\mathrm{v,R}}$
: ：水膜の右のつながりへ出ていく水蒸気の流れ（kg/(m² s)）
:::

である。水膜があるときは、入ってくる水蒸気と出ていく水蒸気の差が凝縮・蒸発の量になる。水膜がないときは、この差は 0 で、熱の流れだけがつり合う。どちらの場合も、凝縮・蒸発の熱は水膜の質点で数えるので、熱が保存される。

水膜の温度を、隣の材料の質点の温度と同じとして、凝縮・蒸発の熱を隣の質点に入れる方法も考えられる。しかし、その方法では水膜の質点だけほかの質点と違う式になる。水膜の質点にもほかの質点と同じ熱の収支の式を使い、熱容量を 0 とするほうが、式が 1 つで済む。

## 4 水膜のあり・なしの切り替え

### 4.1 切り替えの条件

水膜の水分量と水蒸気圧には、次の関係がある。

- 水膜があれば（水分量が正）、水蒸気圧は飽和水蒸気圧である。
- 水膜がなければ（水分量が 0）、水蒸気圧は飽和水蒸気圧以下である。

水膜があるかないかは、そのステップを解いてみないとわからない。後退差分で解くには、ステップの終わりの値で、この関係を満たす必要がある。

### 4.2 考えた方法

次の 3 つの方法を考えた。

1. **仮定して解き、外れていれば解き直す**：まず水膜がないとして解き、水膜の水蒸気圧が飽和水蒸気圧を超えていれば、水膜があるとして解き直す。後退差分になるが、ステップごとに 2 回解くことがあり、仮定の組み合わせが水膜の質点の数だけ増える。
2. **前のステップの値で判定する**：水膜があるかないかだけを、前のステップの値で決める。1 回で解けるが、判定が 1 ステップ遅れ、水膜ができる・なくなるステップで、水分の収支が合わなくなることがある。
3. **1 つの量で表す**：水膜の水分量と水分化学ポテンシャルを、1 つの量（水膜の状態量）で表し、ほかの未知数と一緒にニュートン法で解く。

3 の方法を選んだ。1 回で解け、水膜があるかないかがステップの終わりの値で決まり、水分が厳密に保存されるためである。

### 4.3 水膜の状態量

水膜の状態量 $s$ から、水分化学ポテンシャルと水膜の水分量を、式 {eq}`bf-mu` と式 {eq}`bf-w` で求める（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の式 (10)・(11)）。

$$
\mu_{\mathrm{f}} = \min \left( s, \thinspace 0 \right)
$$ (bf-mu)

$$
W_{\mathrm{f}} = k \max \left( s, \thinspace 0 \right)
$$ (bf-w)

ここで、

:::{container} symbols
$\mu_{\mathrm{f}}$
: ：水膜の質点の水分化学ポテンシャル（J/kg）

$s$
: ：水膜の状態量（J/kg）

$W_{\mathrm{f}}$
: ：水膜の水分量（kg/m²）

$k$
: ：水膜の状態量を水膜の水分量に直す係数（(kg/m²)/(J/kg)）
:::

である。

- 水膜の状態量が負のときは、水膜がない。水分化学ポテンシャルは水膜の状態量そのもので、水蒸気圧は飽和水蒸気圧より低い。
- 水膜の状態量が 0 以上のときは、水膜がある。水分化学ポテンシャルは 0（水蒸気圧は飽和水蒸気圧）で、水膜の水分量は水膜の状態量に比例する。
- 水膜の状態量が 0 のとき、2 つの式はどちらも、水分化学ポテンシャル 0、水膜の水分量 0 を与える。そのため、水分の収支の残差は、水膜の状態量について切れ目なくつながり、傾きだけが変わる。ニュートン法は、修正の幅を半分ずつ小さくする仕組み（「{doc}`数値解法の安定性 <04_05_basis_solver>`」の 5 節）とあわせて、この形の式を解ける。

水分化学ポテンシャルの上限 0（「{doc}`1 ステップの解き方 <03_12_eval_solve>`」の式 (5)）は、水膜の質点には設けない。水膜の状態量が 0 以上の範囲は、水膜があることを表し、残差は水膜の水分量によって変わるので、平らにならないためである。

## 5 係数の決め方

係数 $k$ は、水膜の状態量の目盛りを決めるだけのものである。同じ水膜の水分量を、違う数の水膜の状態量で表すことになるだけで、収束した答え（水膜の水分量、温度、水分化学ポテンシャル）は変わらない。

ただし、ニュートン法の解きやすさには影響する。水膜の質点の水分の収支の残差の、水膜の状態量による傾きは、次の 2 つである。

- 水膜がないとき：両側へ流れる水蒸気の変化で、左右のコンダクタンスの和に、水蒸気圧の水分化学ポテンシャルによる変化（水分化学ポテンシャルが 0 の近くでは、飽和水蒸気圧を、水蒸気のガス定数と温度の積で割った値）を掛けたもの
- 水膜があるとき：水膜の水分量の変化を時間刻みで割ったもので、係数を時間刻みで割ったもの

この 2 つの傾きが大きく違うと、水膜ができる・なくなる所で修正が行き過ぎやすい。そこで、時間刻みが基準の時間のとき、2 つがそろうように、係数を式 {eq}`bf-k` で決めた（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の式 (12)）。

$$
k = \tau \left( G_{\mathrm{m,L}} + G_{\mathrm{m,R}} \right) \frac{p_{\mathrm{vs}} \left( T_{\mathrm{ref}} \right)}{R_{\mathrm{v}} T_{\mathrm{ref}}}
$$ (bf-k)

ここで、

:::{container} symbols
$k$
: ：水膜の状態量を水膜の水分量に直す係数（(kg/m²)/(J/kg)）

$\tau$
: ：基準の時間。 $\tau = 3600$（s）

$G_{\mathrm{m,L}}$
: ：水膜の左のつながりの、境目の湿気コンダクタンス（kg/(m² s Pa)）

$G_{\mathrm{m,R}}$
: ：水膜の右のつながりの、境目の湿気コンダクタンス（kg/(m² s Pa)）

$p_{\mathrm{vs}} \left( T_{\mathrm{ref}} \right)$
: ：基準の温度の飽和水蒸気圧（Pa）

$R_{\mathrm{v}}$
: ：水蒸気のガス定数（J/(kg K)）

$T_{\mathrm{ref}}$
: ：基準の温度。 $T_{\mathrm{ref}} = 293.15$（K）
:::

である。

- 基準の時間には、時間刻みそのものではなく、一定の値を使う。係数が計算の途中で変わると、同じ水膜の状態量が表す水膜の水分量が変わり、水分が保存されなくなる。時間刻みを途中で変える仕組み（「{doc}`数値解法の安定性 <04_05_basis_solver>`」の 9 節）を将来入れても、保存されるようにするためである。
- 基準の温度は、傾きの大きさをそろえる目安であり、正確である必要はない。
- 通気層に面する表面のデフォルトの値（7 節）では、係数は約 $6 \times 10^{-4}$ (kg/m²)/(J/kg) で、水膜 1 kg/m² が水膜の状態量 約 1600 J/kg に当たる。

## 6 層と層の境目にいつも水膜の質点を置く理由

水膜の質点を置く境目を、入力で選ばせる方法もある。そうせずに、層と層の境目にいつも置くことにした。

- **水膜がないあいだの答えは、水膜を置かない場合と同じになる。** 水膜がないあいだ、水膜の質点は水分も熱もためない。水蒸気の流れと熱の流れは、それぞれ水蒸気圧の差と温度の差に比例するので、水膜の質点を通る流れは、左右のコンダクタンスを直列にした値で決まる。左右を直列にした値が、水膜を置かない場合の境目のコンダクタンスと同じなら、答えは同じである。
- **境目の結露で計算が止まらない。** 結露がどの境目で起きるかは、前もってわからないことが多い。いつも置けば、どの境目で結露しても水膜として受けられる。
- **入力と文書が簡単になる。** 置くかどうかの入力と、その場合分けがなくなる。

その代わり、質点の数が増える。「{doc}`支配方程式と離散化 <04_01_basis_equations>`」の 5.3.3 節の 7 層の壁では、層と層の境目が 6 つあり、質点は 33 から 39 に、2 年間の計算の時間は 126 秒から 144 秒（約 14%）に増えた。

外表面と内表面には、水膜の質点を置かない。外表面の水（雨がかかる、露が付く）と内表面の水は、外気・室内との境界の扱いとあわせて考える必要があるためである（11 節）。

## 7 境目のコンダクタンスのデフォルトの値

層と層の境目のコンダクタンスは、水膜の左右の 2 組で与える。左右に分けた値は、水膜ができたとき、水膜がどちら側の抵抗の内側にできるかを決める。たとえば防湿層では、水膜が防湿層の室内側にできるか屋外側にできるかで、水のたまり方が変わる。

値を与えないときのデフォルトの値（「{doc}`熱・水分の流れ <03_05_eval_flows>`」の表 1）は、次の考えで決めた。

- **材料と材料**：材料どうしの接触の値（熱 50 W/(m² K)、湿気 $7.75 \times 10^{-7}$ kg/(m² s Pa)）を、左右で同じ大きさに分けた値（どちらも 2 倍）とした。左右を直列にすると接触の値に戻るので、水膜がないあいだの答えは、接触の値を 1 組で与えた場合と同じである。
- **材料と通気層**：空気の側は、通気層の中の表面の伝達の値（熱 9.2 W/(m² K)、湿気 $3.43 \times 10^{-8}$ kg/(m² s Pa)）とした。材料の側は、材料の表面と水膜のあいだに、塗膜やバックシーラーなどの抵抗がほとんどないことを表す値（熱 1000 W/(m² K)、湿気 $1.0 \times 10^{-5}$ kg/(m² s Pa)）とした。抵抗を 0 にはできない（つながりの抵抗が 0 になり、流れが求められない）ので、表面の伝達より十分大きい値を選んだ。直列にした値は、表面の伝達だけの場合より約 1% 小さい。

材料の側の値は、確かな根拠のある値ではない。バックシーラーや塗膜がある場合は、その値を与える。

7 層の壁の 2 年間の計算では、デフォルトの値を使うことで、前（通気層の表面を表面の伝達だけで与えた場合）と比べて、2 年目の温度の差は最大 0.044 K（平均 0.005 K）、相対湿度の差は最大 0.14%（平均 0.016%）であった。差がもっとも大きいのは、通気層に面する石膏ボードの表面である。この壁では、2 年間で水膜はできなかった。

## 8 浸入する雨水

### 8.1 外表面に当たる雨水

外表面に当たる雨水は、ASHRAE Standard 160 の鉛直な壁の雨量の式（式 (4-6)）で求める（参考文献 [1]）。単位を kg/(m² s) にすると、式 {eq}`bf-rbv` になる（「{doc}`雨水の浸入 <03_14_eval_rain>`」の式 (2)）。

$$
r_{\mathrm{bv}} = \frac{F_{\mathrm{E}} \thinspace F_{\mathrm{D}} \thinspace F_{\mathrm{L}} \thinspace U_{10,\mathrm{w}} \thinspace r_{\mathrm{h}}}{3600}
$$ (bf-rbv)

ここで、

:::{container} symbols
$r_{\mathrm{bv}}$
: ：外表面に当たる雨水（kg/(m² s)）

$F_{\mathrm{E}}$
: ：雨水暴露係数（-）

$F_{\mathrm{D}}$
: ：雨水付着係数（-）

$F_{\mathrm{L}}$
: ：経験的な定数。 $F_{\mathrm{L}} = 0.2$（kg s/(m³ mm)）

$U_{10,\mathrm{w}}$
: ：高さ 10 m の風速のうち、外表面に向かって吹く成分（m/s）

$r_{\mathrm{h}}$
: ：水平面の降水量（mm/h）
:::

である。

- **経験的な定数 $F_{\mathrm{L}}$**：雨粒は、落ちながら風に流されて斜めに降る。鉛直な面に当たる雨の量は、雨粒の水平方向の速さ（風速）と落ちる速さ（終端速度）の比に、水平面の降水量を掛けた量になる。 $F_{\mathrm{L}}$ の単位のうち kg/(m² mm) の部分は、降水量 1 mm を水 1 kg/m² に直す換算で、残りの 0.2 s/m は、雨粒の落ちる速さ 5 m/s の逆数に当たる。ASHRAE Standard 160 によると、もとは Lacy（1965）の式で、平均の雨粒の大きさを仮定しているので、強い雨では多めに見積もる傾向がある。
- **風速の高さ**：式の風速は、高さ 10 m の値である。建物の高さの影響は、風速ではなく、雨水暴露係数の表（「{doc}`雨水の浸入 <03_14_eval_rain>`」の表 1）に含まれている。そのため、気象データの風速を、測った高さから 10 m の値に直して使う（「{doc}`外気の条件 <03_07_eval_outdoor>`」の式 (13)・(14)）。風速を壁の高さの値に直して使うと、建物の高さの影響を、風速と雨水暴露係数の両方で数えることになる。べき指数 0.25 のとき、高さ 6.5 m の風速は 10 m の値の約 0.90 倍で、10 m の値に直すと約 1.11 倍になる。
- **雨水暴露係数と雨水付着係数**：表から、建物の高さと周りの状況（暴露の分類）、屋根と壁の関係（付着の分類）で選ぶ。ASHRAE Standard 160 は、付着の値に大きな不確かさがあるとしている。値は、計算する建物に合わせて必ず与えるものとし、デフォルトの値は設けない。

### 8.2 外表面に向かって吹く風

外表面に向かって吹く風の成分は、高さ 10 m の風速の北向きと東向きの成分から、式 {eq}`bf-uw` で求める（「{doc}`雨水の浸入 <03_14_eval_rain>`」の式 (1)）。

$$
U_{10,\mathrm{w}} = \max \left( U_{10,\mathrm{E}} \sin \alpha_{\mathrm{w}} + U_{10,\mathrm{N}} \cos \alpha_{\mathrm{w}}, \thinspace 0 \right)
$$ (bf-uw)

ここで、

:::{container} symbols
$U_{10,\mathrm{w}}$
: ：高さ 10 m の風速のうち、外表面に向かって吹く成分（m/s）

$U_{10,\mathrm{E}}$
: ：高さ 10 m の風速の東向きの成分。風が東へ吹いていく向きを正とする（m/s）

$U_{10,\mathrm{N}}$
: ：高さ 10 m の風速の北向きの成分。風が北へ吹いていく向きを正とする（m/s）

$\alpha_{\mathrm{w}}$
: ：外表面の方位角。南を 0、西回りを正とする（rad）
:::

である。外表面の外向きの法線（水平な成分）は、東向き $- \sin \alpha_{\mathrm{w}}$、北向き $- \cos \alpha_{\mathrm{w}}$ なので、風のうち外表面に向かって吹く成分は、風の向きと外向きの法線の内積の符号を変えたものになる。これは、ASHRAE Standard 160 の「風速 × 風向と壁のなす角の余弦」と同じ量である。

風速と風向ではなく、成分を使うのは、次の 2 つの理由による。

- 時刻の間を直線で補うとき、風向が北をまたいでも（たとえば 350 deg と 10 deg の間）、正しく補える。
- 気象データの風向は 16 方位（22.5 deg ごと）に丸められていることが多いが、成分には丸めがない。

### 8.3 浸入する割合

外表面に当たった雨水のうち、外装材の内側へ浸入する割合は、ASHRAE Standard 160 では、外皮の仕様の試験の値などがない場合、外装材の表面に達する雨水の 1% とし、防水層の外側の表面にたまるものとしている。

このプログラムでは、浸入する割合を、層と層の境目ごとに与える。

- ASHRAE Standard 160 のとおりに計算するときは、防水層の外側の境目（通気構法の壁では、通気層に面する防水層の表面）に 0.01 を与える。
- 割合の合計が 1 を超えると、当たった雨水より多くの雨水が浸入することになるので、入力の誤りとする。
- 割合の合計が 0.01 を超えても、物理的には誤りではないが、ASHRAE Standard 160 の想定より多くの雨水が浸入するので、注意を表示する。

### 8.4 鉛直な壁だけで扱う理由

ASHRAE Standard 160 の雨量の式は、鉛直な壁に当たる雨の式である。また、ASHRAE Standard 160 は、雨水の浸入を壁だけで扱い、屋根は雨水が浸透しないように設計するものとしている。そのため、雨水の浸入は、外表面の傾斜角が 90 deg の壁だけで扱う。

- 外壁は、わずかに傾いていることもあるので、90 deg ± 5 deg の範囲は鉛直な壁として計算する。ただし、90 deg でないときは、鉛直な壁として計算したことを表示する。
- この範囲の外の面（屋根など）で、浸入する割合を与えたときは、入力の誤りとする。浸入する割合を 0 にすれば、傾いた面も計算できる。

### 8.5 風速の分布で平均をとらない理由

1 時間の中の風速は、一定ではなく、ばらつく。風速の分布（たとえばレイリー分布）で、外表面に当たる雨水の平均をとる方法もある。しかし、式 {eq}`bf-rbv` は風速に比例するので、分布で平均をとった値は、平均の風速を入れた値と同じになる。そのため、分布で平均をとらない。

### 8.6 雨水が持ち込む熱

浸入する雨水は、外気の温度で水膜に入ってくるものとし、水膜の温度との差に水の比熱を掛けた熱を、水膜の質点の熱の収支に加える（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の式 (15)）。水膜の熱容量は 0 としているので、水膜の水そのものの温度の変化は数えず、入ってくる水と水膜の温度の差の分だけを数える。量は小さいが、これを入れると、雨水の出入りについても熱の出入りがそろう。

## 9 流れ落ち

水膜の水分量には上限がないと、強い雨が続いたときに、水膜が際限なく厚くなる。実際の通気層の表面では、ある量を超えた水は流れ落ちる。そこで、流れ落ちずに留まれる量を超えた分が、時定数 $\tau_{\mathrm{d}}$ で壁の外へ流れ出すものとし、式 {eq}`bf-drain` で表す（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の式 (13)）。

$$
j_{\mathrm{drain}} = \frac{\max \left( W_{\mathrm{f}} - W_{\mathrm{f,max}}, \thinspace 0 \right)}{\tau_{\mathrm{d}}}
$$ (bf-drain)

ここで、

:::{container} symbols
$j_{\mathrm{drain}}$
: ：水膜から流れ落ちる水（kg/(m² s)）

$W_{\mathrm{f}}$
: ：水膜の水分量（kg/m²）

$W_{\mathrm{f,max}}$
: ：水膜が流れ落ちずに留まれる水分量。 $W_{\mathrm{f,max}} = 0.005$（kg/m²）

$\tau_{\mathrm{d}}$
: ：留まれる量を超えた水が流れ落ちる時定数。 $\tau_{\mathrm{d}} = 600$（s）
:::

である。

- **時定数で流し出す形にした理由**：留まれる量を超えたときに、一定の量が流れ出す形にすると、強い雨では浸入する量が流れ出す量を上回り、水膜が際限なく厚くなる。また、留まれる量のところで流れ出す量が 0 から跳ぶので、残差が切れ目なくつながらず、ニュートン法が解きにくくなる。時定数で流し出す形なら、超えた量に比例して流れ出し、留まれる量のところで値は切れ目なくつながる（傾きだけが変わる）。
- **値**：留まれる量 5 g/m²（水の厚さにして 5 µm）と時定数 600 s は、仮に決めた値で、測定などによる根拠は確かめていない。時定数は、時間刻み（3600 s）より短くし、留まれる量を超えた水が、おおむねそのステップのうちに流れ出すようにした。
- **流れ落ちた水の行き先**：通気層の中を流れ落ちて、壁の下から外へ出るものとし、ほかの層には入れない（11 節）。

## 10 確かめ

### 10.1 水膜ができて、なくなる確かめ

水膜ができて、なくなることを、2 層の壁で確かめた。壁は、外側に構造用合板 12 mm（分割数 4）、内側にグラスウール 100 mm（分割数 5）とし、境目の水膜の左（合板の側）の湿気コンダクタンスを $2.0 \times 10^{-11}$ kg/(m² s Pa)（防湿層）、右（グラスウールの側）を $1.55 \times 10^{-6}$ kg/(m² s Pa) とした。外表面の湿気コンダクタンスは $2.0 \times 10^{-11}$、内表面は $2.6 \times 10^{-8}$ kg/(m² s Pa) である。初期は 10 deg.C・60% で、時間刻みは 3600 s とした。

表 1　水膜ができて、なくなる確かめ

| 期間 | 外気 | 室内 | 期間の終わりの水膜の水分量 | 水分の保存のずれ | 修正の回数（平均・最大） |
|---|---|---|---|---|---|
| 冬 30 日 | −5 deg.C・80% | 20 deg.C・40% | 1.64 kg/m² | $4 \times 10^{-7}$ kg/m² | 1.12 回・5 回 |
| 続けて夏 60 日 | 25 deg.C・40% | 25 deg.C・40% | 0（相対湿度 40.2%） | $9 \times 10^{-7}$ kg/m² | 1.84 回・5 回 |

- 冬には、防湿層の室内側の水膜に水がたまった。材料の中で結露して計算が止まることはなかった。
- 冬の水膜の水分量は、手で見積もった値とおおむね合う。室内（水蒸気圧 936 Pa）から水膜（約 −3.5 deg.C、飽和水蒸気圧 473 Pa）まで、内表面・グラスウール・水膜の右の抵抗を直列にした透湿抵抗は $6.7 \times 10^{8}$ (m² s Pa)/kg であり、30 日間に入る水蒸気は約 1.8 kg/m² になる。計算の値（1.64 kg/m²）が少し小さいのは、初めの数日は水膜の温度が下がりきっておらず、水膜ができるまでに時間がかかるためである。
- 夏には、水膜の水は両側へ蒸発し、水膜はなくなった。
- 水分の保存のずれは、ニュートン法の許容値の分（ステップ数 × 質点の数 × 水分の許容値 × 時間刻み、約 $10^{-5}$ kg/m²）より小さい。
- 水膜があるときの 1 ステップで、熱（潜熱を含む）が許容値の範囲で保存されることも確かめた（`test/test_solver.py` の `TestFilm`）。

室内の相対湿度を 70% にすると、水膜より先に、グラスウールの中の質点が相対湿度 100% に達し、計算が止まった。この条件では、室内側から入る水蒸気が多く、グラスウールの中でも水蒸気圧が飽和水蒸気圧を超えるため、結露する範囲が断熱材の中まで広がる。材料の中で平衡含水率の最大を超えてたまる水は、まだ扱っていない（11 節）。

### 10.2 浸入する雨水の確かめ

3 層の壁（南向き。構造用合板2 12 mm、換気のない空気層 25 mm、構造用合板2 12 mm）で、空気層と内側の合板の境目に、外表面に当たる雨水の 1% が浸入するようにして、降水量 10 mm/h、壁に正面から 5 m/s の風の雨を 1 日当て続けた（時間刻み 600 s）。

- 水膜に水がたまり、留まれる量（5 g/m²）を超えた分が流れ落ちた。
- 水分は、浸入した雨水と流れ落ちた水を含めて、許容値の範囲で保存された。
- 熱も、雨水が持ち込む熱を含めて、許容値の範囲で保存された（空気層の空気の質点で、水蒸気のままたまった分の潜熱を除く）。

### 10.3 7 層の壁の 2 年間の計算

「{doc}`支配方程式と離散化 <04_01_basis_equations>`」の 5.3.3 節の 7 層の壁（東向き）で、通気層と石膏ボードの境目に、外表面に当たる雨水の 1% が浸入するようにして（雨水暴露係数 1.0、雨水付着係数 1.0。気象データの風速の高さ 6.5 m、べき指数 0.25）、浸入しない場合と 2 年間の計算を比べた。

- 2 年目に外表面に当たった雨水は 242 kg/m²（水平面の降水量 1445 mm の約 17%）で、雨水が当たった時間は 941 時間であった。水膜に浸入した雨水は 2.4 kg/m² である。
- 水膜は、2 年目のどの時刻にもできなかった。水膜の右（石膏ボードの側）のつながりの湿気コンダクタンスがデフォルトの値（ $1.0 	imes 10^{-5}$ kg/(m² s Pa)）で大きいので、浸入した雨水は、水膜の水蒸気圧が飽和水蒸気圧に達する前に、水蒸気として石膏ボードに入るためである。たとえば、浸入する雨水が $3 	imes 10^{-5}$ kg/(m² s)（強い雨の 1 時間）でも、これを流すのに要る水蒸気圧の差は約 3 Pa にすぎない。
- そのため、浸入した雨水は、石膏ボードの通気層側を湿らせた。2 年目の相対湿度は、浸入しない場合と比べて、石膏ボードの通気層側の端の質点で最大 33%（平均 1.6%）、通気層の空気で最大 18%（平均 1.4%）高くなった。温度は、雨水の蒸発・凝縮の熱により、最大 2.1 K 変わった。
- ニュートン法の修正の回数は、平均 2.67 回から 2.69 回になり、最大は 5 回のままであった。

この結果は、浸入した雨水が、どのくらい速く材料に入るかが、水膜と材料のあいだの湿気コンダクタンスで決まることを示している。デフォルトの値は、材料の表面と水膜のあいだに抵抗がほとんどないことを表すので、雨水は水蒸気として速く材料に入る。防水層（透湿防水シートなど）の外側に浸入させるときは、その湿気コンダクタンスを水膜の右（材料の側）の値として与える必要がある。

## 11 扱っていないこと

- **濡れ面率**：水膜が境目の一部だけを覆う場合は扱わない。濡れ面率を掛けると、水膜ができた瞬間に伝達率が跳び、残差が切れ目なくつながらなくなるので、扱い方を考えてから足す。
- **液水としての吸水**：水膜の水が、液水のまま材料に吸い込まれることは扱わない。水膜と材料のあいだは、水蒸気圧の差で書いた湿気コンダクタンスでやりとりする。水膜の水分化学ポテンシャルは 0 なので、材料が乾いていれば水蒸気として材料に入るが、液水として毛管で吸い込まれる速さは表せない。液水としての吸水を扱うときは、次のことを考える必要がある。
  - 水膜と材料のあいだの抵抗を、水蒸気の抵抗（透湿抵抗。水蒸気圧の差に対する抵抗）と液水の抵抗（透水抵抗。水分化学ポテンシャルの差に対する抵抗）に分けて与える。バックシーラーや塗膜は、この 2 つの値が大きく違うことがある。
  - 材料の表面の質点から中への液水の流れに、材料の液相水分伝導率を使う。液相水分伝導率が 0 の材料（今のデータでは多くの材料）では、液水は吸い込まれない。水膜から吸い込まれるときだけ、飽和時の液相水分伝導率など別の値を使うかを決める。
  - バックシーラーの透水抵抗や、外装材の飽和時の液相水分伝導率の値は、出典を確かめてから使う。
- **材料の中の自由水**：材料の中で、平衡含水率の最大を超えて水がたまる場合は扱わない。このときは、結露したものとして計算を止める（「{doc}`1 ステップの解き方 <03_12_eval_solve>`」の 5 節）。
- **外表面と内表面の水**：外表面に雨がかかる・露が付く場合と、内表面の結露は扱わない。
- **屋根などの傾いた面の雨水**：外表面に当たる雨水の式は鉛直な壁の式なので、傾いた面では雨水の浸入を扱わない（8.4 節）。
- **流れ落ちた水の行き先**：流れ落ちた水は壁の外へ出るものとし、同じ境目の下の部分や、ほかの層へ入ることは扱わない。
- **雨水の温度**：雨水は外気の温度で入ってくるものとする。雨粒の温度（湿球温度に近いことが多い）は扱わない。
