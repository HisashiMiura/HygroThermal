# 入力のファイル

## 1 ファイルの形

入力のファイルは JSON（文字コードは UTF-8）で書く。表 1 の 4 つのまとまりを持つオブジェクトである。

表 1　入力のファイルのまとまり

| キー | 中身 | 書き方 |
|---|---|---|
| `wall` | 壁 | 2 節 |
| `outdoor` | 外気（気象データのファイルと、その読み方） | 3 節 |
| `indoor` | 室内 | 4 節 |
| `simulation` | 計算の設定 | 5 節 |

```text
{
  "wall": { "surface": { ... }, "layers": [ ... ], "interfaces": [ ... ],
            "len_vertical": 7.0, "len_horizontal": 0.42 },
  "outdoor": { "weather_file": "weather.csv", ... },
  "indoor": { "type": "cosine", ... },
  "simulation": { "dt": 3600, "years": 2 }
}
```

（`...` は省いた所）

書き方の決まりは、次のとおりとする。

- 表の「省略」の欄に値のないキーは、必ず書く。省けるキーは、省いたときの値をその欄に示す。
- 表にないキー（打ち間違いなど）を書くと、エラーにする。
- 数は、整数でも小数でもよい（`3600` と `3600.0` は同じ）。ただし、整数と書いたもの（分割数など）は整数で書く。`true`・`false` は数として扱わない。
- 単位は表に示すとおりとする。温度は deg.C、相対湿度は % で書く。
- 値がおかしいときは、どのまとまりの、どのキーかを示して、計算を始める前に止める（「{doc}`使い方 <02_01_spec_usage>`」の 3 節）。

例として、7 層の壁を 2 年間計算する入力のファイル `examples/main_wall.json` がある。

## 2 壁（wall）

### 2.1 全体

壁は、外気側から順に並べた層と、層の境目からなる。層が $N$ 枚なら、境目は $N + 1$ 個ある（外気と最初の層の境目、層と層の境目、最後の層と室内の境目）。

表 2　壁

| キー | 意味 | 単位 | 範囲 | 省略 |
|---|---|---|---|---|
| `surface` | 外表面（2.2） | | | |
| `layers` | 層のリスト。外気側から順に並べる（2.3） | | 1 枚以上 | |
| `interfaces` | 境目のリスト。外気側から順に並べる（2.5） | | 層の数 + 1 個 | |
| `len_vertical` | 壁の縦の長さ。壁の面に沿って測った長さで、傾いた面では斜面に沿った長さ | m | 0 より大きい | |
| `len_horizontal` | 壁の横の長さ | m | 0 より大きい | |

縦の長さは、通気層の換気量に使う（「{doc}`通気層の換気 <03_10_eval_ventilation>`」）。

### 2.2 外表面（surface）

表 3　外表面

| キー | 意味 | 単位 | 範囲 | 省略 |
|---|---|---|---|---|
| `direction` | 外表面の方位。`"s"`、`"sw"`、`"w"`、`"nw"`、`"n"`、`"ne"`、`"e"`、`"se"`（南から時計回りの 8 方位）、`"top"`（真上を向いた水平な面）、`"bottom"`（真下を向いた水平な面）のどれか | | | |
| `angle` | 傾斜角。0 は上向きの水平、90 は鉛直、180 は下向きの水平 | 度 | `top` なら 0、`bottom` なら 180、それ以外は 0 より大きく 180 より小さい | |
| `albedo` | 地面の日射反射率 | - | 0 以上 1 以下 | |
| `absorptance` | 外表面の日射吸収率 | - | 0 以上 1 以下 | |
| `emissivity` | 外表面の長波長放射率 | - | 0 以上 1 以下 | |
| `exposure_factor` | 雨水暴露係数 | - | 0 以上 | |
| `deposition_factor` | 雨水付着係数 | - | 0 以上 | |

日射吸収率・放射率・アルベドの使い方は「{doc}`外表面の日射・夜間放射 <03_09_eval_surface_solar>`」に、雨水暴露係数・雨水付着係数の選び方は「{doc}`雨水の浸入 <03_14_eval_rain>`」の表 1・表 2 に示す。

### 2.3 層（layers）

層は、材料の層（表 4）か通気層（表 5）である。`air_layer` のキーがあれば通気層、なければ材料の層として読む。

表 4　材料の層

| キー | 意味 | 単位 | 範囲 | 省略 |
|---|---|---|---|---|
| `source` | 材料の出どころ。`"whamcavity"` か `"mews_ashrae"`（2.4） | | | |
| `name` | 材料の名前（2.4） | | | |
| `thickness` | 厚さ | m | 0 より大きい | |
| `n_div` | 層の中の質点の数（整数）。層の両端に質点を置く | - | 2 以上 | |
| `initial_temperature` | 初期の温度 | deg.C | | |
| `initial_rh` | 初期の相対湿度 | % | 0 より大きく 100 より小さい | |
| `porosity` | 空隙率。与えると、質点の水分量が空隙を水で満たす水分量を超えたときに計算を止める | - | 0 より大きく 1 以下 | 確かめない |
| `wood_decay` | 木材腐朽を求めるか（`true` か `false`） | | | `false` |

表 5　通気層

| キー | 意味 | 単位 | 範囲 | 省略 |
|---|---|---|---|---|
| `air_layer` | 通気層であることを示す。`true` と書く | | | |
| `thickness` | 厚さ | m | 0 より大きい | |
| `alpha` | 流量係数。0 なら換気のない空気層 | - | 0 以上 | |
| `initial_temperature` | 初期の温度 | deg.C | | |
| `initial_rh` | 初期の相対湿度 | % | 0 より大きく 100 より小さい | |

層の並べ方には、次の決まりがある。

- いちばん外側といちばん内側の層は、材料の層にする（外気と室内に面する表面には、材料の質点が要るため）。
- 通気層を 2 枚続けて並べない（1 枚の通気層にまとめる）。

質点の置き方は「{doc}`壁の構成と質点 <03_04_eval_wall_nodes>`」に、空隙率と自由水の扱いは「{doc}`熱・水分の収支 <03_11_eval_balance>`」の 7 節と「{doc}`1 ステップの解き方 <03_12_eval_solve>`」の 6 節に、木材腐朽は「{doc}`木材腐朽 <03_15_eval_decay>`」に示す。

### 2.4 材料の名前

材料の物性値は、出どころごとの Excel のファイル（`modules/` の下）から読む。名前は、その Excel のとおりに書く。

- `"whamcavity"`：Fortran 版の 19 材料。表 6 のとおり。
- `"mews_ashrae"`：MEWS の材料と ASHRAE の材料（81 材料）。

表 6　出どころ `"whamcavity"` の材料の名前

| 名前 |
|---|
| シージング、通気層、グラスウール1、木材、構造用合板1、石膏ボード、ALC、軟質繊維版、サーモプライ、サイディング、土壁、軽量モルタル、セルロースファイバー、発泡プラスチック1、発泡プラスチック2、発泡プラスチック3、グラスウール2、集成材、構造用合板2 |

どちらの出どころも、名前の一覧は次のようにして出せる。

```
python -c "from modules.material_loaders import load_materials; print([m.name for m in load_materials('mews_ashrae')])"
```

名前がその出どころにないときは、壁を作るとき（計算を始める前）にエラーにする。物性値の式は「{doc}`材料の性質 <03_03_eval_materials>`」に示す。

### 2.5 境目（interfaces）

境目のコンダクタンスは、表面の伝達、層と層の接触、塗膜・防湿層などの抵抗を、1 つにまとめた値である。境目では、水蒸気は移動するが、液水は移動しない。

**外表面と内表面の境目**（リストの最初と最後）は、表 7 の 1 組で書く。

表 7　外表面・内表面の境目

| キー | 意味 | 単位 | 範囲 | 省略 |
|---|---|---|---|---|
| `g_h` | 熱コンダクタンス | W/(m² K) | 0 より大きい | |
| `g_m` | 湿気コンダクタンス | kg/(m² s Pa) | 0 より大きい | |

**層と層の境目**（それ以外）には、いつも水膜の質点を置く。コンダクタンスは、水膜の左（外気側）と右（室内側）の 2 組で書く（表 8）。

表 8　層と層の境目

| キー | 意味 | 単位 | 範囲 | 省略 |
|---|---|---|---|---|
| `left` | 水膜の左のコンダクタンス。表 7 の形（`g_h` と `g_m`） | | | 下の文 |
| `right` | 水膜の右のコンダクタンス。表 7 の形 | | | 下の文 |
| `rain_fraction` | 外表面に当たる雨水のうち、この境目の水膜に浸入する割合 | - | 0 以上 1 以下 | 0（浸入しない） |

`left`・`right` を省くと、境目の両側の層の種類（材料と材料、材料と通気層、通気層と材料）で決まる値にする。値とその意味は「{doc}`熱・水分の流れ <03_05_eval_flows>`」の 1.2 節の表 1 に示す。何も指定しない境目は `{}` と書く。

雨水の浸入には、次の決まりがある（「{doc}`雨水の浸入 <03_14_eval_rain>`」）。

- `rain_fraction` の合計は 1 以下にする。合計が 0.01（ASHRAE Standard 160 のデフォルト）を超えると、警告を出す。
- 雨水を浸入させるのは、鉛直な壁（傾斜角 90 度 ± 5 度）だけとする。それ以外の面で浸入させるとエラーにする。90 度でなければ、鉛直な壁として計算することを警告する。

例：`examples/main_wall.json` の境目（層 7 枚、境目 8 個）。外表面、層と層の境目 6 個、内表面の順である。外気側から 6 個目の境目（グラスウールと、室内側の構造用合板の間）だけ、水膜の右（構造用合板の側）を防湿層の値にしている。

```json
"interfaces": [
  {"g_h": 22.4, "g_m": 2e-11},
  {}, {}, {}, {},
  {"left": {"g_h": 100.0, "g_m": 1.55e-06}, "right": {"g_h": 100.0, "g_m": 2e-11}},
  {},
  {"g_h": 9.2, "g_m": 2.6e-10}
]
```

## 3 外気（outdoor）

外気は、1 時間ごと 1 年分の気象データのファイルと、その読み方で与える。

表 9　外気

| キー | 意味 | 単位 | 範囲 | 省略 |
|---|---|---|---|---|
| `weather_file` | 気象データのファイルの場所。入力のファイルがあるフォルダからの場所で書く（絶対パスでもよい） | | | |
| `latitude` | 緯度（北緯を正） | 度 | -90 以上 90 以下 | |
| `longitude` | 経度（東経を正） | 度 | -180 以上 180 以下 | |
| `radiation_kind` | 日射・夜間放射の値の種類。`"instant"`（瞬時値）か `"interval"`（1 時間の積算値・平均値） | | | |
| `radiation_interval` | 日射・夜間放射の値が、どの 1 時間の値か。`"before"`（h − 1 〜 h 時）、`"centered"`（h − 0.5 〜 h + 0.5 時）、`"after"`（h 〜 h + 1 時）のどれか。`radiation_kind` が `"interval"` のときだけ使う | | | |
| `radiation_unit` | 日射・夜間放射の単位。`"W/m2"` か `"MJ/(m2 h)"` | | | |
| `rain_interval` | 降水量の値が、どの 1 時間の値か。`radiation_interval` と同じ書き方 | | | |
| `wind_height` | 気象データの風速を測った高さ | m | 0 より大きい | |
| `wind_exponent` | 風速を高さ 10 m の値に直すべき乗則のべき指数 | - | 0 以上 | |

気象データのファイルの形と、これらの設定の意味は、「{doc}`気象データのファイル <02_03_spec_weather>`」に示す。緯度・経度・風速の高さ・べき指数の範囲は、気象データを読むときに確かめる。

## 4 室内（indoor）

室内は、`type` で種類を選ぶ。今は、室温が 1 年周期の余弦で変わり、相対湿度が一定の `"cosine"` だけがある（表 10）。

表 10　室内（`"type": "cosine"`）

| キー | 意味 | 単位 | 範囲 | 省略 |
|---|---|---|---|---|
| `type` | 室内の種類。`"cosine"` と書く | | | |
| `theta_in_ave` | 年平均の室温 | deg.C | | |
| `theta_in_amp` | 室温の振幅 | K | 0 以上 | |
| `rh_in` | 室内の相対湿度 | % | 0 より大きく 100 以下 | |
| `d_peak` | 室温がいちばん高い日の通算日（整数。1 月 1 日が 1） | d | 1 以上 365 以下 | 212 |

## 5 計算の設定（simulation）

表 11　計算の設定

| キー | 意味 | 単位 | 範囲 | 省略 |
|---|---|---|---|---|
| `dt` | 時間刻み | s | 0 より大きい。計算する期間が `dt` の整数倍になること | |
