# 結果のファイル

## 1 書き出すファイル

計算の結果は、書き出すフォルダ（「{doc}`使い方 <02_01_spec_usage>`」の 2 節）に、表 1 のファイルとして書き出す。CSV は表計算のソフトなどで見るためのもの、HDF5 は値を 2 進数のまま残すためのものである。

表 1　結果のファイル

| ファイル | 中身 |
|---|---|
| `nodes.csv` | 質点の表（2.1） |
| `temperature.csv` | 温度（2.2） |
| `relative_humidity.csv` | 相対湿度（2.2） |
| `water_content.csv` | 材料の含水量（2.3） |
| `free_water.csv` | 材料の自由水の量（2.3） |
| `film_water.csv` | 水膜の水分量（2.3）。水膜の質点があるときだけ書く |
| `drained.csv` | 流れ落ちた水の累計（2.3）。水膜の質点があるときだけ書く |
| `mass_loss.csv` | 木材腐朽の質量減少率（2.2）。木材腐朽を求める層があるときだけ書く |
| `result.h5` | 上のすべてと、水分化学ポテンシャルの欄の値、修正の回数、計算の入力、最後まで計算したかどうか（3 節） |

値は、最初の状態（経過時間 0）と、入力の `record_interval`（「{doc}`入力のファイル <02_02_spec_input>`」の 5 節）ごとの状態を記録したものである。経過時間は、1 月 1 日 0 時から数えた秒である。

## 2 CSV

CSV の文字コードは、BOM（ファイルの先頭の、UTF-8 であることを示す印）付きの UTF-8 とする。表計算のソフト（Excel など）で開いても、日本語（材料の名前）が化けないようにするためである。Python の標準の `csv` で読むときは、文字コードを `utf-8-sig` とする（pandas は指定しなくても読める）。1 行目は列の名前とする。小数は、読み直したときに計算の値と同じ値に戻る、いちばん短い書き方で書く。

### 2.1 質点の表（nodes.csv）

1 行が 1 つの質点で、外気側から順に並ぶ。列は表 2 のとおりである。質点の置き方は「{doc}`壁の構成と質点 <03_04_eval_wall_nodes>`」に示す。

表 2　質点の表の列

| 列 | 意味 | 単位 |
|---|---|---|
| `index` | 質点の番号（0 から） | - |
| `layer` | 層の番号（入力の `layers` の並びで、0 から）。水膜の質点は、左（外気側）の層の番号 | - |
| `kind` | 質点の種類。`material`（材料）、`air`（通気層の空気）、`film`（層と層の境目の水膜） | - |
| `material` | 材料の名前（材料の質点だけ。ほかは空） | - |
| `x` | 外表面からの位置。材料の質点は質点の位置、通気層の空気の質点は層の真ん中、水膜の質点は境目の位置 | m |
| `width` | コントロールボリュームの幅（水膜の質点は 0） | m |
| `wood_decay` | 木材腐朽を求める質点なら `True` | - |

### 2.2 温度・相対湿度・質量減少率（temperature.csv、relative_humidity.csv、mass_loss.csv）

1 行が 1 つの記録した時刻で、表 3 の列が並ぶ。`node_i` の `i` は、質点の表の `index` である。

表 3　温度・相対湿度・質量減少率の表の列

| 列 | 意味 | 単位 |
|---|---|---|
| `time_s` | 記録した時刻（経過時間） | s |
| `node_0`、`node_1`、… | 各質点の値 | 温度は deg.C、相対湿度は %、質量減少率は -（0 以上 1 以下の割合） |

相対湿度は、温度と水分化学ポテンシャルから求めた値である（「{doc}`湿り空気と水の性質 <03_02_eval_air_water>`」）。材料の質点と水膜の質点は、相対湿度 100% を超える水（自由水、水膜の水）を持てるが、相対湿度は 100% を超えない（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の 6 節・7 節）。

質量減少率は、木材腐朽を求めない質点では 0 である（「{doc}`木材腐朽 <03_15_eval_decay>`」）。

### 2.3 水分量（water_content.csv、free_water.csv、film_water.csv、drained.csv）

表 3 と同じ形の表で、列はそれぞれ表 4 の質点だけを並べる。`node_i` の `i` は、質点の表の `index` である。

表 4　水分量の表

| ファイル | 中身 | 列 | 単位 |
|---|---|---|---|
| `water_content.csv` | 材料の含水量。平衡含水率の分と自由水の量の和（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の式 (1)）を、コントロールボリュームの幅で割ったもの | 材料の質点 | kg/m³ |
| `free_water.csv` | 材料の自由水の量（相対湿度 100% の平衡含水量を超えてたまった水。同じく式 (17)）を、コントロールボリュームの幅で割ったもの | 材料の質点 | kg/m³ |
| `film_water.csv` | 水膜の水分量（同じく式 (11)）。壁 1 m² あたり | 水膜の質点 | kg/m² |
| `drained.csv` | 計算を始めてから、水膜から流れ落ちた水の累計（「{doc}`時間の進め方 <03_13_eval_time>`」の式 (2)）。壁 1 m² あたり | 水膜の質点 | kg/m² |

相対湿度は 100% を超えないので、結露してたまった水の量は、自由水の量と水膜の水分量で見る。

## 3 HDF5（result.h5）

HDF5 は、名前の付いた配列をいくつも 1 つのファイルに入れる形式で、Python（h5py）のほか、MATLAB、R、Julia、C、Fortran などで読める。値は 2 進数のまま入れるので、計算の値とまったく同じ値が読める。どの配列にも、単位（属性 `unit`）と意味（属性 `description`）を付けている。

ファイルの属性は表 5、配列は表 6 のとおりである。質点ごとの配列の形は [質点, 記録した時刻] である（行が質点）。CSV（行が時刻）とは向きが逆であることに注意する。

表 5　HDF5 のファイルの属性

| 属性 | 意味 |
|---|---|
| `completed` | 最後まで計算したら `True`、途中で止まったら `False` |
| `message` | 止まった理由（最後まで計算したら空） |
| `time_failed` | 解けなかったステップの終わりの時刻, s（最後まで計算したら NaN） |
| `input` | 入力のファイルの中身（そのままの文字列） |

表 6　HDF5 の配列

| 配列 | 形 | 意味 | 単位 |
|---|---|---|---|
| `time` | [記録] | 記録した時刻（経過時間） | s |
| `temperature` | [質点, 記録] | 温度 | K |
| `relative_humidity` | [質点, 記録] | 相対湿度（2.2） | % |
| `mu` | [質点, 記録] | 水分化学ポテンシャルの欄の値。材料の質点と水膜の質点は状態量 $s$ で、水分化学ポテンシャルは $\min(s, 0)$ | J/kg |
| `mass_loss` | [質点, 記録] | 木材腐朽の質量減少率 | - |
| `water_amount` | [質点, 記録] | 水分量。壁 1 m² あたり。材料の質点は平衡含水率の分と自由水の量の和、通気層の空気の質点は水蒸気の量、水膜の質点は水膜の水分量（「{doc}`熱・水分の収支 <03_11_eval_balance>`」の式 (1)・(2)・(11)） | kg/m² |
| `free_water` | [質点, 記録] | 材料の自由水の量。壁 1 m² あたり。ほかの質点は 0 | kg/m² |
| `drained` | [質点, 記録] | 流れ落ちた水の累計。壁 1 m² あたり。水膜の質点のほかは 0 | kg/m² |
| `iterations` | [ステップ] | 各ステップのニュートン法の修正の回数 | - |
| `nodes/layer`、`nodes/kind`、`nodes/material`、`nodes/x`、`nodes/width`、`nodes/wood_decay` | [質点] | 質点の表（2.1 の表 2 と同じ） | 表 2 のとおり |

温度は、CSV では deg.C、HDF5 では K である。材料の水分量は、CSV では kg/m³（コントロールボリュームの幅で割ったもの）、HDF5 では kg/m²（壁 1 m² あたり）である。状態量 $s$ の意味は、「{doc}`熱・水分の収支 <03_11_eval_balance>`」の 6 節・7 節に示す。

## 4 計算が止まったとき

計算が途中で止まったとき（「{doc}`使い方 <02_01_spec_usage>`」の 4 節）も、表 1 のファイルを書き出す。

- 記録は、止まる前の最後の記録までとする。最初のステップで止まったときは、最初の状態だけになる。
- `iterations` は、解けたステップまでとする。
- HDF5 の属性 `completed` を `False` にし、`message` と `time_failed` に、止まった理由と時刻を入れる。

## 5 Python で読む例

```python
import h5py
import pandas as pd

# CSV：行が時刻、列が質点
theta = pd.read_csv('case_output/temperature.csv', index_col='time_s')

# HDF5：行が質点、列が時刻
with h5py.File('case_output/result.h5', 'r') as f:
    completed = f.attrs['completed']
    t = f['temperature'][()]          # K
    rh = f['relative_humidity'][()]   # %
    kind = f['nodes/kind'].asstr()[()]
```
