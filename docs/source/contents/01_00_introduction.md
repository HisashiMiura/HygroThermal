# 注意事項

## 1 この文書の構成

この文書は、次の 4 つの部からなる。

| 部 | 内容 |
|---|---|
| 注意事項 | この文書を読むための約束（記号・添え字・時刻の書き方など） |
| プログラムの仕様 | プログラムの使い方、入力の形、気象データの指定。プログラムの中の名前（変数・関数など）と、この文書の記号との対応も示す |
| 評価方法 | 計算の手順。各時刻の値を、そのまま計算できる形の式で示す |
| 評価方法の根拠 | 評価方法の式の導き方と、そのように決めた理由 |

評価方法と評価方法の根拠は、プログラムの作りによらない計算方法として書く。プログラムの中の名前は、プログラムの仕様にだけ書く。

## 2 評価方法の各節の構成

評価方法の各節は、原則として次の順に書く。

1. はじめに：その節で何を計算するか、入力と出力
2. 記号及び添え字：その節で使う記号（記号・意味・単位）と添え字（添え字・意味）の表
3. 以降：計算の式

式には節ごとに 1 から番号を付け、本文では「式 (1)」のように参照する。

## 3 単位

単位は SI 単位とする。ただし、次の量は慣用の単位も使う。

| 量 | 記号 | 単位 |
|---|---|---|
| 温度（熱力学温度） | $T$ | K |
| 温度（セルシウス温度） | $\theta$ | deg.C（ $\theta = T - 273.15$ ） |
| 相対湿度 | $\varphi$ | %（式の中では 0〜1 の比で使うことがある。その場合は節の中で示す） |

熱・水分の流れと、質点の水分量・熱容量は、壁 1 m² あたりの量とする。

## 4 向き

壁の厚さ方向は 1 次元とし、外気側を左、室内側を右とする。つながりの流れ（熱・水蒸気・液水）は、外気側から室内側へ向かう向きを正とする。

質点 $i$ の左のつながりは $k = i$、右のつながりは $k = i + 1$ である。そのため、質点 $i$ に左から入ってくる流れから、右へ出ていく流れを引いたものは、つながりの番号を使って $j_i - j_{i+1}$ と書く（流れが負のときも、この式のまま成り立つ）。

## 5 添え字

各節で共通に使う添え字は、次のとおりとする。

| 添え字 | 意味 |
|---|---|
| $i$ | 質点の番号（外気側から 0, 1, 2, …, $N - 1$。 $N$ は質点の数） |
| $k$ | つながりの番号（0, 1, …, $N$。つながり $k$ は質点 $k - 1$ と質点 $k$ の間。つながり 0 は外気と質点 0 の間、つながり $N$ は質点 $N - 1$ と室内の間） |
| $l$ | 層の番号（外気側から 0, 1, 2, …） |
| $n$ | 時刻のステップの番号（計算を始めた時刻が 0） |
| $h$ | 1 時間ごとの気象データの行の番号（1 月 1 日 0 時が 0） |
| $\mathrm{ex}$ | 外気（external） |
| $\mathrm{in}$ | 室内（internal） |

### 添え字の書体

数式の中では、値が変わる量の記号（ $T$・ $t$ など）と、数が入る番号の添え字（ $i$・ $k$・ $l$・ $n$・ $h$）は斜体で書く。言葉の略の添え字（ $\mathrm{ex}$・ $\mathrm{in}$・ $\mathrm{sol}$・ $\mathrm{vent}$ など）、関数（ $\sin$・ $\exp$ など）は立体で書く。例えば、外気の温度は $T_{\mathrm{ex}}$、質点 $i$ の温度は $T_i$ と書く。

## 6 時刻の書き方

時刻のステップ $n$ は、記号の右上に書く。場所を表す添え字（ $i$・ $k$ など）は右下に書く。例えば、ステップ $n$ の質点 $i$ の温度は $T_i^n$、ステップ $n + 1$ の温度は $T_i^{n+1}$ と書く。

時間の刻みを $\Delta t$ とし、ステップ $n$ の時刻を $t^n = n \Delta t$ とする。評価方法では、ステップ $n$ の値から、ステップ $n + 1$ の値を求める。熱・水分の流れは、ステップ $n + 1$ の値で計算する（後退差分）。

$$
\frac{W_i^{n+1} - W_i^n}{\Delta t} = j_i^{n+1} - j_{i+1}^{n+1}
$$

（上の式は書き方の例で、記号の意味は評価方法の各節で示す。）
