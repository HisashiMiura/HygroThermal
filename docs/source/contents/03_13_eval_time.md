# 時間の進め方

## 1 はじめに

### 1.1 概要

本節では、壁の初期の状態から、時間刻みごとに 1 ステップずつ状態を進める方法と、時刻の決め方、結果の記録のしかたを定める。

### 1.2 入力

:::{container} symbols
$\Delta t$
: ：時間刻み。0 より大きくする（s）

$N_{\mathrm{step}}$
: ：進めるステップの数。0 以上の整数とする（-）

$N_{\mathrm{rec}}$
: ：何ステップごとに結果を記録するか。1 以上の整数とする（-）

$T_{i,0}$
: ：質点 $i$ の初期の温度。「{doc}`壁の構成と質点 <03_04_eval_wall_nodes>`」で求める（K）

$\mu_{i,0}$
: ：質点 $i$ の初期の水分化学ポテンシャル。「{doc}`壁の構成と質点 <03_04_eval_wall_nodes>`」で求める（J/kg）
:::

### 1.3 出力

:::{container} symbols
$T_{i,n}$
: ：記録するステップ $n$ の質点 $i$ の温度（K）

$\mu_{i,n}$
: ：記録するステップ $n$ の質点 $i$ の水分化学ポテンシャル（J/kg）

$t_n$
: ：記録するステップ $n$ の時刻（s）
:::

また、各ステップのニュートン法の修正の回数を出力する。

## 2 記号及び添え字

### 2.1 記号

:::{container} symbols
$N_{\mathrm{rec}}$
: ：何ステップごとに結果を記録するか（-）

$N_{\mathrm{step}}$
: ：進めるステップの数（-）

$T_{i,n}$
: ：ステップ $n$ の質点 $i$ の温度（K）

$t_n$
: ：ステップ $n$ の時刻。1 月 1 日 0 時からの経過時間（s）

$\Delta t$
: ：時間刻み（s）

$\mu_{i,n}$
: ：ステップ $n$ の質点 $i$ の水分化学ポテンシャル（J/kg）
:::

### 2.2 添え字

:::{container} symbols
$i$
: ：質点の番号

$n$
: ：時刻のステップ。 $0, 1, \ldots, N_{\mathrm{step}}$
:::

## 3 時刻

計算を始める時刻を 1 月 1 日 0 時とし、ステップ $n$ の時刻 $t_n$ は、式 {eq}`tm-t` により計算される。

$$
t_n = n \thinspace \Delta t
$$ (tm-t)

1 年は 365 日とし、うるう年は考えない。2 年目以降も、同じ 1 年の周期で続ける（気象データは 1 年分を繰り返して使う）。

## 4 1 ステップの進め方

ステップ $n = 0, 1, \ldots, N_{\mathrm{step}} - 1$ の順に、ステップ $n$ の状態から、次の手順でステップ $n + 1$ の状態を求める。

1. 時刻 $t_{n+1}$ の外気の条件と室内の条件を、「{doc}`外気の条件 <03_07_eval_outdoor>`」と「{doc}`室内の条件 <03_08_eval_indoor>`」により求める。
2. 時刻 $t_{n+1}$ の外表面に外から直接入る熱を、「{doc}`外表面の日射・夜間放射 <03_09_eval_surface_solar>`」により求める。
3. ステップ $n$ の質点の温度と、時刻 $t_n$ の外気の温度から、換気量を「{doc}`通気層の換気 <03_10_eval_ventilation>`」により求める。
4. 「{doc}`熱・水分の収支 <03_11_eval_balance>`」の収支の式を満たすステップ $n + 1$ の温度と水分化学ポテンシャルを、「{doc}`1 ステップの解き方 <03_12_eval_solve>`」により求める。

時刻 $t_n$ の外気の条件は、ひとつ前のステップの手順 1 で求めたものを使う。最初のステップ（ $n = 0$）では、時刻 $t_0 = 0$ の外気の条件を求める。

「{doc}`1 ステップの解き方 <03_12_eval_solve>`」の 5 節により計算を止めたときは、そこで計算を終える。

## 5 記録

初期の状態（ステップ 0）と、ステップ $n$ が $N_{\mathrm{rec}}$ の倍数のときの状態を、時刻 $t_n$ とともに記録する。 $N_{\mathrm{rec}} = 1$ なら、すべてのステップを記録する。

記録の間隔によらず、最後のステップ $N_{\mathrm{step}}$ の状態も出力する（続きの計算に使うため）。
