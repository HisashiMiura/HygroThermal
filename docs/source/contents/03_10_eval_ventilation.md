# 通気層の換気

## 1 はじめに

### 1.1 概要

本節では、ステップ $n$ の、通気層の空気の質点の換気量の求め方を定める。換気は、通気層の空気と外気の温度差による浮力で起きるものとし、風による換気は扱わない。通気層に入ってくる空気は外気とする。ここで求める換気量は、換気で入る熱・水分として、熱・水分の収支に使う（「熱・水分の収支」）。

### 1.2 入力

:::{container} symbols
$\alpha_l$
: ：通気層 $l$ の流量係数。0 以上とする（-）

$d_l$
: ：通気層 $l$ の厚さ。「{doc}`壁の構成と質点 <03_04_eval_wall_nodes>`」の入力（m）

$L_{\mathrm{vert}}$
: ：壁の縦の長さ。壁の面に沿って測った長さで、傾いた面では斜面に沿った長さとする（m）

$\beta_{\mathrm{w}}$
: ：外表面の傾斜角。「{doc}`外表面の日射・夜間放射 <03_09_eval_surface_solar>`」の入力（deg）

$T_{i,n}$
: ：ステップ $n$ の質点 $i$ の温度（K）

$T_{\mathrm{ex},n}$
: ：ステップ $n$ の外気の温度。「{doc}`外気の条件 <03_07_eval_outdoor>`」の温度に $T_0$ を足したもの（K）
:::

### 1.3 出力

:::{container} symbols
$q_{\mathrm{v},i,n}$
: ：ステップ $n$ の、質点 $i$ の壁 1 m² あたりの換気量（m³/(m² s)）
:::

$T_{i,n}$
: ：ステップ $n$ の質点 $i$ の温度（K）

$T_{\mathrm{ex},n}$
: ：ステップ $n$ の外気の温度（K）

$\alpha_l$
: ：通気層 $l$ の流量係数（-）

$\beta_{\mathrm{w}}$
: ：外表面の傾斜角。上向きの水平を 0、垂直を 90、下向きの水平を 180 とする（deg）

: ：ステップ $n$ の質点 $i$ の空気の密度（kg/m³）

## 3 壁の下端と上端の高さの差

通気層は、壁の下端から上端まで通っているものとする。壁の下端と上端の高さの差 $H$ は、式 {eq}`vt-h` により計算される。傾斜角は、rad に換算した値とする。

$$
H = L_{\mathrm{vert}} \sin \beta_{\mathrm{w}}
$$ (vt-h)

水平な面（ $\beta_{\mathrm{w}} = 0$、180 deg）では $H = 0$ となり、浮力による換気は起きない。

## 4 換気量

ステップ $n$ の外気の密度 $\rho_{\mathrm{a,ex},n}$ と、通気層の空気の質点 $i$ の空気の密度 $\rho_{\mathrm{a},i,n}$ は、それぞれ $T_{\mathrm{ex},n}$ と $T_{i,n}$ から、「{doc}`湿り空気と水の性質 <03_02_eval_air_water>`」の式 (6) で求める。

ステップ $n$ の、通気層 $l$ の空気の質点 $i$ の壁 1 m² あたりの換気量 $q_{\mathrm{v},i,n}$ は、式 {eq}`vt-qv` により計算される。

$$
q_{\mathrm{v},i,n} = \frac{\alpha_l \thinspace d_l}{L_{\mathrm{vert}}} \sqrt{\frac{2 g H \left| \rho_{\mathrm{a,ex},n} - \rho_{\mathrm{a},i,n} \right|}{\rho_{\mathrm{a,ex},n}}}
$$ (vt-qv)

材料の質点の換気量は 0 とする。流量係数が 0 の通気層は、換気のない空気層である。

換気量は、ステップ $n$ の値を、ステップ $n$ から $n + 1$ までのあいだ一定として使う。

## 5 根拠

換気量の式の導き方（浮力による圧力差とオリフィスの式、壁の横の長さが消えること）、高さの差を縦の長さと傾斜角から求める理由、換気で入る熱・水分の式、換気量をステップの中で一定にする理由は、「{doc}`通気層の換気のモデル <04_03_basis_ventilation>`」に示す。
