# 根拠のページの試算

計算方法の文書の根拠のページ（`docs/source/contents/04_*.md`）に載せている試算の数字を出すスクリプト。モデルやデータを変えたときに、同じ条件で計算し直して、文書の数字を確かめる。

## 使い方

リポジトリの一番上のフォルダで、次のように実行する。

```
conda run -n heat_load_calc python docs/basis_checks/check_04_01_vapour_storage.py
```

- 例の壁（`examples/one_year_main_wall.py` の 7 層の壁）の 2 年間の計算の結果は、`docs/basis_checks/_out/` に保存して使い回す（git には入れない）。保存した結果があれば計算し直さないので、モデルを変えたあとは `--force` を付けて計算し直す。
- 例の壁の 2 年間の計算は、時間刻み 3600 s で約 3 分、900 s で約 10 分かかる。
- `check_04_01_vapour_storage.py` は、ほかのスクリプトが使う基準の計算（`_out/base.npz`）も作るので、最初に実行する。そのあとのスクリプトは、並べて実行してよい。

## スクリプトと、数字を載せている所

| スクリプト | 根拠のページ | 出す数字 |
|---|---|---|
| `check_04_01_vapour_storage.py` | 支配方程式と離散化 5.3.3 節、10.4 節 | 空隙の水蒸気を省く近似の影響（図 1 も描き直す）、水分容量で書いた場合のずれ（表 3） |
| `check_04_03_ventilation.py` | 通気層の換気のモデル 表 1、8.2 節 | 換気量の例、換気量をニュートン法の中で計算し直すと止まるステップ |
| `check_04_04_weather_interval.py` | 気象データと時刻 表 3〜表 5 | 気象データの日射の表し方の確かめ、区間を取り違えた影響 |
| `check_04_05_solver.py` | 数値解法の安定性 表 1〜表 3、6.2 節 | 許容値、修正の行き過ぎを抑える仕組み、修正の回数の下限、修正の回数の分布 |
| `check_04_06_film.py` | 境目にたまる水（水膜）のモデル 4.4 節、8.7 節 | 2 層の壁で水膜ができて、なくなる例、雨水を浸入させた 7 層の壁の計算（塗膜の値を含む） |
| `check_04_07_free_water.py` | 材料の中の自由水のモデル 表 1・表 2、5.4 節、7 節 | 空隙を水で満たす量、空隙率を与えたときに止まる日 |
| `check_04_08_decay.py` | 木材腐朽のモデル 表 1〜表 6、図 1 | 発芽までの時間、反応速度定数（図 1 も描き直す）、腐朽で生まれる水の影響、判定に使う値、係数 WS による違い |

## スクリプトにしていない数字

- **テストで確かめているもの**：根拠のページで「（`test/...`）」と書いた確かめは、テスト（`pytest`）で確かめる。
- **前のコードとの比べ**：「前（〜の場合）と比べて」のように、今はないコードの計算と比べた数字（たとえば、水膜の質点を置く前の計算時間）は、記録として残しているもので、計算し直せない。
- **液水拡散係数の段差の影響**（材料の性質の扱い 5.2 節）と、**平衡含水率の段差の影響**（同じく 4.3 節）：外気の相対湿度の上げ方や、段差をなくした液水拡散係数の作り方など、条件の細部の記録が残っていないので、スクリプトにしていない。
