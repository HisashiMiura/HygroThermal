# 材料のファイルの 6 列目（CGGD）の意味について（Whamcavity の mcoff1.prn）

2026-11-14 · Hisashi Miura

## 要旨

Whamcavity の材料のファイル mcoff1.prn には、6 列目に CGGD という列があります。Python 版に移すときに、この列を「空隙率（porosity）」として読み込んでいましたが、密度の小さい断熱材で 1 を超えるなど、空隙率としては説明できない値でした。Fortran 版のプログラムはこの列を読んでいないので、計算には影響しません。ただ、材料の中の水蒸気の量を計算に入れるには空隙率が要るので、この列が何の量か、確認をお願いできればと思います。

## 該当箇所

mcoff1.prn の見出しと、材料の行の一部です。

```
K	RMD	RMDD	CGG	GMA	CGGD
3	0.045	1.58E-10	8.40E+02	16	1.19
4	0.0824	1.86E-12	1.62E+03	484	0.928
5	0.16	4.58E-12	1.86E+03	600	0.864
```

Whamcavity.f95 では、5 列目までしか読んでいません。

```fortran
READ(11,*)K,RMDH(I),RMDG(I),GCP(I),GMA(I)
```

## 空隙率として説明できない点

| 材料 | 乾燥密度 GMA, kg/m³ | CGGD |
| --- | --- | --- |
| グラスウール1 | 16 | 1.19 |
| グラスウール2 | 16 | 1.181 |
| セルロースファイバー | 38.6 | 1.154 |
| 発泡プラスチック1〜3 | 30〜40 | 1.152〜1.164 |
| 木材 | 484 | 0.928 |
| 構造用合板1 | 600 | 0.864 |
| サイディング | 1095 | 0.72 |
| 軽量モルタル | 1091 | 0.612 |

- 空隙率は 1 を超えませんが、密度の小さい断熱材ではすべて 1 を超えています。
- 木材の空隙率を、乾燥密度と木材の実質の密度（約 1500 kg/m³）から見積もると約 0.68 で、0.928 と合いません。
- 密度が大きいほど値が小さくなる傾向はあります。

## 確認したいこと

1. CGGD は何の量でしょうか（名前の意味、単位）。
2. 値の出どころ（文献や測定）はどこでしょうか。
3. 材料の空隙率のデータがあれば、教えていただけないでしょうか。今は、材料の中の水蒸気の量を省く近似を使っていて、その影響を確かめるときの空隙率は、乾燥密度から見積もっています。
